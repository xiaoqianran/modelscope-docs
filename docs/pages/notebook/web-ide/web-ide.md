# Web IDE Entry Point

Based on the computing power and storage support provided by the ModelScope platform, ModelScope Notebook also offers a Web IDE entry point based on VS Code, enabling developers to perform more convenient and efficient development work within the Notebook environment. The Web IDE, combined with persistent storage capabilities (see the **Storage Description** section in [Notebook Introduction](./Notebook介绍.md) for details), provides a more complete development experience. Therefore, like persistent storage, the Web IDE is currently only available on PAI-DSW-based Notebooks and can be accessed through the entry point in the top right corner:

![img.png](./_resources/ide-entry.png)

After entering the Web IDE page, you'll see the familiar VS Code interface. At this point, the icon in the top right corner becomes the entry point to return to Jupyter "Notebook," allowing easy switching between Web IDE and Jupyter Notebook.

![img.png](./_resources/vs-code-1.png)

Developers can freely use familiar VS Code features based on the underlying CPU or GPU resources, including Auto-Completion (may have slight delay due to remote connection), breakpoint debugging, Terminal window, and more.

![img.png](./_resources/debug.png)
