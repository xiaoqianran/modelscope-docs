This article introduces ModelScope community's content compliance review policy.

The ModelScope platform encourages developers to share high-quality, easy-to-use models to improve algorithm development efficiency and accelerate model research and innovation. During usage, the ModelScope community expects users to take responsibility for content sharing and dissemination, and not to share information that violates Chinese laws or social ethics. For detailed scenarios, please refer to [User Agreement and Privacy Policy](user-agreement-and-privacy-policy.md). To the extent permitted by law, we are not responsible for any public display or misuse of content you create or upload. However, we have the right to remove content that we or authorized regulatory agencies deem to violate any laws or platform agreements or policies, in order to maintain a healthy and friendly community environment.

# Review Standards
We will conduct content compliance reviews during file uploads, information filling, Demo services, and other processes. The review standards are as follows:

- Whether it contains politically sensitive content
- Whether it contains pornographic content
- Whether it contains violent or terrorist content
- Whether it contains prohibited content
- Whether it contains advertisements or meaningless spam information

# Review Scope
If your uploaded **text, images, audio, video, files**, and **submission information attached to files (e.g., commit messages)** contain any of the above violations, we have the right to delete the violating information and files, and notify you of the handling information. The review scope includes but is not limited to user-uploaded dataset files, model files, and model Demo inputs.

# Review Process
After you upload model files via web or Git commands, you will see the following prompt in the web interface model and dataset file list, indicating that the file is under review. The review time is generally within 3-5 minutes:

![image.png](./_resources/1660120578739-9b969091-413d-43f0-9ffa-91f84cd10e4c.png)

If the Demo input violates regulations, you will receive the following prompt below the input box:

![image.png](./_resources/F4238905-CBE6-4574-9711-97205B704AD3.png)

If the review passes, your uploaded files will become publicly accessible.

# How to Resolve
If your violating or suspected violating files are deleted, you can check the file content yourself, make modifications, and re-upload.
