# 1. Play Style Selection
On the Quick Image Generation page, we offer multiple preset play styles for users to choose from, including:

**1. General Style**: Suitable for most scenarios, capable of generating high-quality images based on descriptions.

**2. Flux Model Image Generation**: Utilizes the latest Flux model, excelling at creating delicate and realistic image styles.

**3. SD3 Model Image Generation**: Leverages the SD3 (Stable Diffusion v3) model, focusing on generating images with rich details and vibrant colors.

**4. Anime Style**: Specifically designed for anime enthusiasts, easily creating artworks with Japanese or American comic styles.

**5. Pixel Art Style**: A favorite among retro gaming fans, generating pixelated images that evoke classic game visuals.

**6. Ink Wash Painting**: Integrates traditional Chinese art, generating images with a strong ink wash aesthetic.

**7. Miyazaki Style**: Mimics the warmth and fantasy found in Hayao Miyazaki's animated films, creating unique animation-style images.

**8. Claymation Style**: Inspired by clay animation, creating distinctive and playful 3D-effect images.

Users can select different play styles based on their preferences and needs, using text to spark unlimited visual imagination and generate desired images.

# 2. Image Description
Users need to input specific descriptions or keywords, and the system will generate corresponding images based on this information.

Image descriptions can include information about text descriptions, colors, styles, emotions, etc., such as "sunset scene on a summer beach with warm tones." Both Chinese and English input are supported (maximum 200 characters).

# 3. Image Aspect Ratio
Users can select different image aspect ratios for generation. We provide multiple ratio options including 1:1 (square), 1:2 (vertical rectangle), 4:3 (widescreen), 3:4 (portrait), 16:9 (HD video ratio), 9:16 (mobile screen ratio), etc. Users can choose the appropriate ratio based on their needs to generate desired images.

![image.png](./_resources/图片比例.png)

# 4. Number of Images to Generate
Users can choose to generate 1, 2, 4, or 8 images.
Users can select the number of images to generate based on their needs, allowing them to generate multiple images at once for easy comparison of results.

# 5. Image Generation
**Operation Process**: After selecting a play style, entering prompts, choosing image aspect ratio and quantity, users can click the "Start Image Generation" button to initiate the generation process.

**Waiting Notification**: Due to resource allocation and server performance management, the system may implement a queuing mechanism during peak hours. Please be patient, and we will process your request as soon as possible.

**Advanced Feature Guidance**: If the images generated by Quick Image Generation do not meet your requirements, we recommend you click to jump directly to the professional image generation page to explore more advanced image generation features.

# 6. Generation History
Users can click the generation history button to view previously generated images. When hovering over an image, you will see the following function buttons:

1. Download Original Image: Save the original image to your local device with one click;
2. Load Parameters: Import the image generation parameters with one click, immediately reproducing the creation process on the current page for easy adjustment and optimization;
3. Jump to Professional Image Generation: Directly enter professional mode for a deeper image editing experience;
4. Generate Share Link: Quickly create a dedicated sharing link for the image, copy with one click, and share your visual story with friends, family, or social media followers.
