# Developer Forum

ModelScope provides an official sub-community within the Alibaba Cloud Developer Community. The team regularly publishes the latest product news, learning paths, technical discussions, and more. For details, please follow: [**ModelScope Community**](https://developer.aliyun.com/space/modelscope/)
<br/>ModelScope has established 5 technical domain-specific sections: [**Computer Vision**](https://developer.aliyun.com/space/modelscope/cv), [**Speech**](https://developer.aliyun.com/space/modelscope/speech), [**Natural Language Processing**](https://developer.aliyun.com/space/modelscope/nlp), [**Multimodal**](https://developer.aliyun.com/space/modelscope/multimodal), and [**Scientific Computing**](https://developer.aliyun.com/space/modelscope/scientific-computing). You can choose the appropriate section based on your model interests to post and interact.

- Computer Vision/Speech/Natural Language Processing/Multimodal/Scientific Computing: These sections support discussions on ModelScope models/datasets/Studios usage issues across different technical domains, and provide model tutorials, event information, official blogs, and other resources.

ModelScope's library is now also open-sourced on GitHub. Developers are welcome to download, use, and contribute to secondary development: [**ModelScope Open Source Repository**](https://github.com/modelscope/modelscope)
