# Text Generation Task

The text generation task is the process of converting input text into tensors, feeding them into a model, and generating readable textual output. Text generation tasks can solve specific problems such as text continuation and article summarization. Below are downstream task applications of text generation models available on ModelScope:

- [Text Continuation](https://modelscope.ai/models/damo/nlp_gpt3_text-generation_13B/summary): Given a text prompt, continue generating subsequent content
- [Understanding-Generation Joint Model](https://modelscope.ai/models/damo/nlp_plug_text-generation_27B/summary): Can be directly used for text generation, or fine-tuned for various text understanding tasks
- [Summary Generation](https://modelscope.ai/models/damo/nlp_palm2.0_text-generation_chinese-base/summary): Given input text, generate a summary of its content
- [Zero-shot Learning Model](https://modelscope.ai/models/ClueAI/PromptCLUE/summary): With a custom label system; can perform free-form sampling generation for various generation tasks
- [Product Copy Generation](https://modelscope.ai/models/damo/nlp_palm2.0_text-generation_commodity_chinese-base/summary): Given a product and some selling points, generate product copy descriptions related to those selling points
- Other scenarios: The model is trained to generate content based on user input text according to user expectations

## Inference for Text Generation Tasks

ModelScope framework's inference capability is implemented through the pipeline module. For basic usage methods of inference, please refer to [Model Inference Pipeline](../模型推理Pipeline.md).

For text generation tasks, you can use it as follows:

```python
from modelscope.pipelines import pipeline
input = 'Yesterday, Shanghai Metro Line 3 implemented further passenger flow restrictions at Changjiang South Road Station, Yingao West Road Station, and Jiangwan Town Station. Experience shows that during peak hours, it takes about 5 minutes to enter the station after queuing; many passengers choose to wake up earlier, "Now I wake up 10 to 20 minutes earlier, so even with flow restrictions, it won't affect my commute to work." Fellow commuters affected by flow restrictions, how much earlier do you wake up? Xinmin Network'
text_summary = pipeline('text-generation', model='damo/nlp_palm2.0_text-generation_chinese-base')
text_summary(input)
```

Below we provide the Pipeline for text generation tasks and supported parameters.

### TextGenerationPipeline

This Pipeline will call a subclass or DuckType class of TextGenerationPreprocessorBase preprocessor for preprocessing, then feed the processed data to the model for forward inference. During a single pipeline generation, multiple forward inferences are performed to generate output sequences composed of tokens, which are then converted to readable text content in the Pipeline's post-processing step.

#### Constructor Parameters

```text
model: Model ID, local model path, or model instance.
preprocessor: The preprocessor corresponding to the model. If not provided, the pipeline will automatically construct one using the configuration file from the downloaded model's local path. If a model instance (e.g., torch.nn.Module class) is passed, ensure it contains a `model_dir` attribute with the local path containing the configuration file to construct a preprocessor.
kwargs: You can pass any parameters needed for the preprocessor constructor here. The default `sequence_length` value is 128.
Other parameters: Any parameters supported by the Pipeline base class can be passed.
```

#### Input Format

```text
str: A single sentence.
```

#### Output Format

```text
Output is a dict with the following key:
text: The text content generated by the model
```

#### Model Compatibility Requirements

##### Model Return Values

**forward**
```text
Returns a dict type or ModelScope's officially defined `TextGenerationModelOutput` type and its subclasses
Required fields:
logits: Model output logits corresponding to the vocabulary, with shape (batch_size, vocab_size)
```

**generate**
```text
Returns a dict type or ModelScope's officially defined `TokenGeneratorOutput` type and its subclasses
Required fields:
sequences: Token sequences generated by the model, with shape (batch_size, sequence_length)
```

##### Preprocessor Requirements
```text
Any subclass or Duck Type class that conforms to the constructor and method requirements of the text generation preprocessor base class `TextGenerationPreprocessorBase`.
```

## Preprocessors for Text Generation Tasks

The base class for text generation task preprocessors is `TextGenerationPreprocessorBase`.

When users employ text generation task preprocessors, the common parameters (i.e., constructor parameters of this base class) are:

```text
model_dir: Local model path containing label_mapping.json for parsing label2id mapping. If label2id is passed via parameters, model_dir can be empty.
src_txt: Key corresponding to input text in the training data dict
tgt_txt: Key corresponding to output text in the training data dict
mode: Operating mode of the preprocessor, with three available values: `train`, `eval`, `inference`. Default is `inference`. Can be used to execute different logic in __call__.
```

Subclasses must implement either of the following methods:

- Either __call__ or _tokenize_text (whichever is implemented, __call__ is the actual preprocessing process)

The definition of the __call__ method is:
```text
def __call__(self, data: Union[str, Tuple, Dict], **kwargs) -> Dict[str, Any]:
    ...
```

_tokenize_text is called within __call__, and its definition is:
```text
def _tokenize_text(self, sequence1, sequence2=None, **kwargs):
    ...
```

The default __call__ method workflow is:
```text
1. The call method defaults to parsing input and output text from the input data as follows:
   - If input is str, treat it as sentence 1.
   - If input is dict: parse according to src_txt and tgt_txt from the constructor parameters.
2. After parsing, call _tokenize_text for embedding. Users can also override only _tokenize_text to execute specific tokenization processes.
3. To adapt to torch_default_collator, convert List-type tensors to numpy.ndarray-type tensors
```

Any training and inference for text generation tasks can use the methods defined in the base class, and additional methods provided by specific subclasses can be used when appropriate.

### TextGenerationTransformersPreprocessor

This class is a text classification task preprocessor implementation based on Transformers' Tokenizer. It can adapt to any general Transformers codebase models, such as PALM, PLUG, etc.

In addition to supporting base class methods, this class supports additional constructor parameters:

```text
use_fast: Use fast or slow version of tokenizer. If this value is not passed, it will attempt to parse from the tokenizer_config.json file in model_dir. If neither exists, it defaults to using the slow version of tokenizer.
kwargs: Any runtime parameters supported by transformers' tokenizer can be passed here, such as commonly used max_length, padding, etc. Default max_length is set to 128, and padding defaults to 'max_length'.
```

This class overrides the _tokenize_text method. kwargs passed during the __call__ phase will be forwarded and merged to override constructor kwargs for tokenization.

This class returns torch tensors when mode is `inference`, and returns numpy tensors when mode is `train` or `eval` to allow the trainer to convert a minibatch to torch tensors.

```python
from modelscope.preprocessors.nlp import TextGenerationTransformersPreprocessor
from modelscope.utils.hub import snapshot_download

model_dir = snapshot_download('damo/nlp_palm2.0_text-generation_chinese-base')
preprocessor = TextGenerationTransformersPreprocessor(
    model_dir=model_dir,
    padding=True,
    max_length=256,
)

# Cover `padding` in the init method.
print(preprocessor('test word', padding=False))
# {'input_ids': tensor([[  101, 10060,  8681,   102]]), 'token_type_ids': tensor([[0, 0, 0, 0]]), 'attention_mask': tensor([[1, 1, 1, 1]])}
```

## Best Practices for Training Tasks

Text generation task training can be performed using ModelScope Library's provided TextGenerationTrainer. If you need to review the basic training process, please check the [Model Training Documentation](../模型的训练.md).

### Loading a Dataset

Taking the DuReader question generation dataset as an example, load this dataset as follows:

```text
from modelscope.msdatasets import MsDataset
dataset = MsDataset.load('DuReader_robust-QG')
```

The DuReader dataset belongs to downstream question generation tasks and can be used to train question generation models for scenarios such as FAQ mining.

### Configuring Preprocessor

Datasets can be preprocessed by user code before calling the trainer, or preprocessor configuration can be written into configuration files and automatically preprocessed within the trainer. Trainer preprocessing occurs when train_loop or evaluation_loop retrieves values from the dataloader.

User code preprocessing logic is not listed here. Users can use any custom workflow for operations like embedding on data. Note that if external preprocessing is performed, ensure the preprocessing field in the configuration file is set to None.

Below is an example configuration for preprocessor information using `TextGenerationTransformersPreprocessor`.

Make the following modifications in cfg_modify_fn provided by TextGenerationTrainer:

```text
cfg.preprocessor = {
  'train': {
      # Configure preprocessor name
      'type': 'text-gen-tokenizer',
      # Configure src_txt key
      'src_txt': 'text1',
      # Configure tgt_txt key
      'tgt_txt': 'text2',
      # Configure mode
      'mode': 'train',
  },
  'val': {
      # Configure preprocessor name
      'type': 'text-gen-tokenizer',
      # Same as above
      'src_txt': 'text1',
      'tgt_txt': 'text2',
      'mode': 'eval',
  }
}
```

### Configuring Training Information

Model training information generally exists in the model configuration file provided by ModelHub (though values like max_epochs need to be filled). Here we assume this configuration doesn't exist and provide a reasonable configuration from scratch:

```text
# Pass the number of labels required by the model
cfg['train'] = {
    "work_dir": "/tmp",
    "max_epochs": 10,
    "dataloader": {
        # batch_size
        "batch_size_per_gpu": 16,
        "workers_per_gpu": 0
    },
    "optimizer": {
        # optimizer information
        "type": "SGD",
        "lr": 0.01,
        "options": {
            "grad_clip": {
                "max_norm": 2.0
            }
        }
    },
    "lr_scheduler": {
        # lr_scheduler information, note torch version compatibility
        "type": "StepLR",
        "step_size": 2,
        "options": {
            "warmup": {
                "type": "LinearWarmup",
                "warmup_iters": 2
            }
        }
    },
    "hooks": [{
        "type": "CheckpointHook",
        "interval": 200,
        "by_epoch": False,
    }, {
        "type": "EvaluationHook",
        "interval": 200,
        "by_epoch": False,
    }]
 }
```

### Configuring Evaluation Information

Similar to the training field, we assume there's no evaluation information in the configuration file and provide usable evaluation information from scratch:

```text
cfg['evaluation'] = {
    "dataloader": {
        # batch_size
        "batch_size_per_gpu": 16,
        "workers_per_gpu": 0,
        "shuffle": false
    },
    "metrics": [{
        "type": "text-gen-metric",
        "target_text": "tgts",
        "pred_text": "preds",
    }]
 }
```

ModelScope provides a standard [Metrics](../详细教程/模型的评估.md) for text generation tasks: TextGenerationMetric, which is the name used in the metrics.type field in the configuration above. This Metric can return Rouge-1, Rouge-L, BLEU-1, and BLEU-4 metric values. If custom evaluation processes are needed, please refer to the specific construction methods in the Metrics link.

### Complete Example

```python
import os

from modelscope.msdatasets import MsDataset
from modelscope.trainers import build_trainer


def cfg_modify_fn(cfg):
    cfg.preprocessor = {
        'train': {
            # Configure preprocessor name
            'type': 'text-gen-tokenizer',
            # Configure src_txt key
            'src_txt': 'text1',
            # Configure tgt_txt key
            'tgt_txt': 'text2',
            # Configure mode
            'mode': 'train',
        },
        'val': {
            # Configure preprocessor name
            'type': 'text-gen-tokenizer',
            # Same as above
            'src_txt': 'text1',
            'tgt_txt': 'text2',
            'mode': 'eval',
        }
    }
    cfg['train'] = {
        "work_dir": "/tmp",
        "max_epochs": 10,
        "dataloader": {
            # batch_size
            "batch_size_per_gpu": 16,
            "workers_per_gpu": 0
        },
        "optimizer": {
            # optimizer information
            "type": "SGD",
            "lr": 0.01,
            "options": {
                "grad_clip": {
                    "max_norm": 2.0
                }
            }
        },
        "lr_scheduler": {
            # lr_scheduler information, note torch version compatibility
            "type": "StepLR",
            "step_size": 2,
            "options": {
                "warmup": {
                    "type": "LinearWarmup",
                    "warmup_iters": 2
                }
            }
        },
        "hooks": [{
            "type": "CheckpointHook",
            "interval": 1,
            "by_epoch": False,
        }, {
            "type": "EvaluationHook",
            "interval": 1,
            "by_epoch": False,
        }]
    }
    cfg['evaluation'] = {
        "dataloader": {
            # batch_size
            "batch_size_per_gpu": 16,
            "workers_per_gpu": 0,
            "shuffle": False
        },
        "metrics": [{
            "type": "text-gen-metric",
            "target_text": "tgts",
            "pred_text": "preds",
        }]
    }
    return cfg


dataset = MsDataset.load('DuReader_robust-QG')

kwargs = dict(
    model='damo/nlp_palm2.0_pretrained_chinese-base',
    train_dataset=dataset['train'],
    eval_dataset=dataset['validation'],
    cfg_modify_fn=cfg_modify_fn)

os.environ['LOCAL_RANK'] = '0'
trainer = build_trainer(name='text-generation-trainer', default_args=kwargs)
trainer.train()
```

The Trainer also supports continued training, saving models with best metrics, and other features. For details, please refer to the [Model Training Documentation](../模型的训练.md).
