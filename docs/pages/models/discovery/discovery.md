# Model Discovery and Experience

This article introduces the model discovery and online demo experience features of ModelScope.

Log in to the ModelScope website and click on Models to view all models available on the community platform. You can filter models by task type or search by model name or keywords. The community model repository is continuously expanding with new content—join our community to contribute your interesting ideas and content! More high-quality models and datasets are being added regularly, so stay tuned.<br>
![image.png](./_resources/F66DE390-8D62-4b5c-820E-A1B1B707FB17.png)<br>
You can filter models by task or other tags, or directly search for model names or descriptions using the search box. The system will match and display relevant models for you.

If you're interested in a particular model, click on its card to view detailed information. The model detail page provides comprehensive content including model description, performance evaluation, associated datasets, and referenced papers. On the right side of the model card, you'll find an online demo experience where you can switch between examples to view the model's input/output results and JSON output.<br>

![image.png](./_resources/268244DE-0B35-4d0b-B8C3-91C5BC3F3F49.png)<br>

Currently, online demos are only available for select models. In the future, we will support users integrating their own online demo modules based on templates.
Before using the online demo feature, please carefully read and understand the relevant [Disclaimer](../user-agreement/user-agreement-and-privacy-policy.md) and ensure compliant and lawful use of the online demo module functionality.<br>

If you're satisfied with the model's performance and want to further explore and verify it through code, click "Quick Start" to view specific code examples. The platform provides two methods for model download:
1) Install and download via ModelScope Library.
2) Clone the repository using git.
Both methods allow you to run models locally. However, you'll need to install the ModelScope Library first before running the code. For details, refer to Step 2 [Environment Setup] - [Local Development Environment Installation].

We also provide online Notebooks with pre-configured runtime environments for models, eliminating the need for users to install dependencies manually. This offers a smoother experience and is recommended for in-depth model exploration! For more details, see Step 2 [Environment Setup] - [Development in Notebook].<br>

If you're satisfied with the model, you can click the favorite button. After favoriting, you can access the model through your Personal Center - My Activity.<br>
