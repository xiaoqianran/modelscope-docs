# Become a Community Certified Model

This article introduces how to become a certified model in the ModelScope community.

To improve the usability, quality, and user experience of models in the ModelScope community, ModelScope provides a service to help contributors obtain usability certification. Certified community models will display a certification badge on the model page, helping users better filter models. Certified models will also receive more traffic and ranking preference!<br />![image.png](./_resources/v1.5p3.png)

Contributors who wish to apply for ModelScope community certification can follow these steps:<br />In [Model Details Page] - [Settings] - [Apply for Community Certification], clicking "Apply" will show a popup window indicating the requirements needed to achieve certification:<br />![image.png](./_resources/v1.5p4.png)

To become a community certified model, three conditions must be met:

1. Model example code must be functional. You can provide example code for running the model in your README document or quickstart document. After submitting your certification application, ModelScope community staff will test and verify the usability of your model example code.
2. Model description content must be complete. Provide necessary model descriptions in your README document, such as model principles, usage limitations, metrics, environment dependencies, application scenarios, reference papers, etc. Content is not limited to these items, but please ensure users can clearly understand the model's purpose through the README content.
3. Model Demo must be functional. If your model has integrated demo tools, please self-test that the model demo has default examples and that the examples can run successfully. After submitting your certification application, ModelScope community staff will perform secondary testing for confirmation. If your model does not have Demo service or does not require Demo service, you can still check this item and submit.

Please ensure your model meets the above conditions before applying for community certification. After submitting your application, community staff will complete the review within 3-5 working days. The final result will be communicated to you via site messages.

If your model review is not approved, the corresponding rejection reasons will be provided. Please adjust your model example code or content according to the rejection reasons. The adjusted model can still reapply for certification.
