# Model Management Settings

This article introduces how to manage datasets in the ModelScope community.

First, you can only manage settings for datasets that you own or administer. After you create a model, you can retrieve your model using the model name, or find your created models in [Personal Center] - [My Spaces] - [My Models].<br>
![image.png](./_resources/1659697865037-42fa3797-0b6a-4cdb-b7b8-c3ee23d13e4e.png)<br>
Click on the model card to access model settings management. On the "Settings" page, you can edit the model's Chinese name, owner, model description, modify the model's open-source license agreement, or change the dataset visibility permissions.<br>
![image.png](./_resources/1659697924320-8958275b-998d-4205-916a-928e1cb23984.png)<br>
![image.png](./_resources/1659450580568-256d9398-2660-4229-a12e-6b0566788287.png)<br>
You can also delete the model from this page. Please note that if you need to delete a model, secondary verification is required. This deletion operation cannot be undone, and all files in the model repository will be permanently deleted. Please proceed with caution!<br>
![image.png](./_resources/1659450607260-76f072ec-0c6f-48d2-81bb-f95d1262de09.png)
