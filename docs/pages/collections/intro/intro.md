ModelScope has launched a new Collection feature 🎉! Collections is an efficient content organization feature designed to help users easily organize and showcase related content and information.

By creating collections, users can integrate scattered resources into theme-specific, well-structured sets, making them easier to share, review, and manage 📖.



# How to Create a New Collection
1. Access entry points: After logging in, users can find the "Collections" entry in:
   1. The "More" dropdown menu in the navigation bar.
   2. The personal center page or the "My Creations" page.
2. Create a collection: After logging in, users can find the "Create Collection" button in:
   1. The dropdown menu under their profile avatar in the top-right corner of the homepage.
   2. The personal center page or the "My Creations" page.
3. Fill in collection information:
   1. **Collection Name**: Enter a concise and clear title that summarizes the collection's theme.
   2. **Owner**: Choose the owner of this collection, which can belong to an individual or an organization.
   3. **Visibility**: Select the collection's visibility, with public being the default setting.
   4. **Collection Description**: Provide a brief introduction outlining the collection's content, purpose, or features.
4. Save creation: After confirming the information is correct, click the **"Create"** button to complete the collection creation.

![image.png](./_resources/创建合集.png)

Additionally, you can dynamically create a collection when adding the first item from a resource page (models, datasets, studios, etc.). For example, when selecting **"+Add to Collection"** from the top-right corner of a model detail page, you can also create a new collection.


## Collection Visibility

### Public Collections

> Definition: Any user can search for and access this collection.

Created collections are public by default and will be displayed at the top of your personal or organization page. Anyone can view them, making them suitable for knowledge sharing, showcasing work, or team public projects.

Note: The first 2 items in each collection (supporting pinning) can be directly previewed on the collection card, but users must click to navigate to the collection detail page to view more content.

![img.png](./_resources/合集卡片预览.png)


### Private Collections

> Definition: Only the collection creator or users with read permissions in the creator's organization can access it.

If you want your collection to be private, you can select private during creation or use the settings button in the top-right corner of the collection detail page to **"Set as Private Collection"**.


Private collections are only visible to the creator or users with read permissions in the creator's organization, making them suitable for personal notes, internal team documentation, or other privacy-sensitive scenarios.



# Adding Items to Collections
There are currently two ways to add content to collections:

- From any resource (model, dataset, studio, etc.) page: Click the **"+Add to Collection"** button in the top-right corner of any resource page (e.g., model detail page), then select an existing collection or choose "Create New Collection" to add it to the corresponding collection.
![img.png](./_resources/加入合集.png)
- From the collection detail page: If you know the name of the content you want to add, click the **"+"** button in the top-right corner of the collection detail page to open a search popup, then search for the corresponding content and add it to the collection.
![img.png](./_resources/搜索添加.png)

> PS: You can add content created by external users or organizations to your collection, not just your own creations.

## Adding Annotations to Collection Items
You can add annotations to any content in your collection to provide additional context (for others or as a reminder for yourself). When you hover over a content card, you can click the **"Edit Note"** button to add annotations.
![img.png](./_resources/添加备注.png)

If you no longer need an annotation you've added, you can click **"Clear Note"** on the edit note page to delete it.

### Text Annotations
1. Edit mode: On the collection detail page, click the "Edit Note" button on the content card to enter edit mode.
2. Enter annotation: Input your comments, explanations, or summaries in the pop-up text box.
3. Save annotation: After completion, click the "Save" button, and the annotation will appear below the content card.

> Annotations use plain text format to maintain simplicity and clarity.

### Image Annotations
Similarly, you can attach images to collection items. This is very useful for showcasing model outputs, dataset contents, additional infographics, etc.

1. Upload image: When editing annotations, use the image upload feature to select an image as part of the annotation.
2. Confirm save: After completion, click the "Save" button, and both image and text annotations will be saved together.

> For a single resource item, you can add up to 5 image annotations.

## Changing the Order of Content in Collections

You can change the order of your collection using the **"Pin to Top"** button on content cards in the collection page.

> The first two items will be directly displayed on your collection card's external page.


## Removing Content from Collections
To remove content from a collection, hover over the content card and click the **"Remove"** button that appears to delete the desired content.
