This article provides a detailed introduction to dataset file maintenance features and important considerations. For dataset creation, please refer to the "Creating Datasets" section in [Dataset Introduction](./dataset-introduction.md).

# Core Concepts
- **[Pre-release]** To ensure the quality of datasets on our platform, we have introduced a file review mechanism for all contributor datasets. Currently, this review mechanism checks for the following conditions, and if any one is met, the dataset will be marked as pre-release status:
    - English name contains and only contains "test".
    - Chinese name contains and only contains "test", or Chinese name contains and only contains the characters "测试" (testing).
    - The dataset contains only the following types of files:
        - README.md
        - dataset_infos.json
        - Dataset-named JSON file or empty dataset-named Python file. Note: If the Python file is not empty, it can exit pre-release status.

    Once you have uploaded your dataset files to the hub and your uploaded dataset does not meet any of the above conditions, we will automatically mark your dataset as **pre-release (preview) status**. In pre-release status, **the resource will not be displayed on listing pages or searchable**. We encourage more developers to share datasets within the ModelScope community, while also hoping to work together with developers to improve dataset quality.

- **[Dataset Files]** Actual data files, supporting multiple formats and organizational methods:
  - Single file support, including formats such as csv, json, jsonl, txt, parquet, etc.
  - Multi-file organization support, including folders, multi-file compressed packages, etc.
  - Dataset-named Python files for specifying dataset organization and loading methods.

# Dataset Maintenance
![image.png](./_resources/1659854600601-8780585c-f957-4bb9-a72c-55e581ce7521.png)
Dataset introduction content is generated by parsing the README.md file in the metadata files. To facilitate user adoption, we recommend including dataset description, overview, data format, dataset loading methods, dataset copyright, citation methods, and other content.

To facilitate README.md file maintenance, the system provides a corresponding file [generator tool](https://www.modelscope.cn/#/readmeformatter). After manual selection, you can directly paste the automatically generated content into the corresponding editing window to quickly generate dataset description content.

# Data Preview
![image.png](./_resources/1659854718253-6e385ea5-61cf-4c25-a500-4d32e2c1b57e.png)
You can preview data files in the dataset, supporting preview of the first 1000 data entries by sub-dataset and usage. Preview content is automatically generated by the system.
If preview content cannot be automatically generated, possible reasons include:

- The dataset is still being parsed and preview data has not yet been generated;
- Correct dataset information was not provided according to specification requirements, see [Dataset File Specification](./dataset-file-specification.md);
- Due to network restrictions, the system cannot access datasets hosted on public hosts;
- For datasets hosted on ModelScope, zip packages greater than or equal to 5GB do not support the preview feature;

# Splitting Datasets
Typically, for a dataset to be well-utilized, it needs to be properly divided into training set (train), validation set (validation), and test set (test) based on usage (split) concepts. For very large datasets, we also introduce the concept of sub-datasets (subset). Therefore, a complete dataset after splitting will have the following three levels:
- Namespace/Name
- Sub-dataset (subset name)
- Usage

A dataset can contain multiple sub-datasets. For example, a natural language processing training set can be divided into different subsets by language. Each sub-dataset can contain one or more of training, testing, and validation usages.

# Deleting Datasets
You can only manage settings for datasets that you own or administer. Please navigate to the dataset card you wish to delete and click on the "Settings" page. Here you can edit the dataset's Chinese name and description, modify the dataset's open-source license agreement, or change the dataset's visibility permissions. You can also delete the dataset from this page.

![image.png](./_resources/1660923430468-b8a09d0c-f9d5-4793-9361-025cb81bdbcc.png)

Please note that if you need to delete a dataset, secondary verification is required. This deletion operation is irreversible, and all files in the dataset will be permanently deleted. Please proceed with caution!
