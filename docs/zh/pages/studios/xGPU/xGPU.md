# xGPU创空间介绍

modelscope魔搭社区上新增支持xGPU创空间部署形态！
xGPU部署为创空间开发者提供了免费的多种类型GPU资源，助力魔搭社区上更丰富的AI应用生态发展。

## xGPU的优势
### 1. 高效的调度策略
基于云上多样化的GPU资源，xGPU提供了根据用户实时请求，进行实时GPU资源调度的能力。

每个用户的请求，将会被按需调度到可用的GPU硬件上，并在必要的计算完成之后，迅速触发GPU资源的释放，来满足其他服务请求。
![image.png](./_resources/xgpu_intro.png)

### 2. 优秀的兼容性
xGPU兼容常见的各种推理引擎、Python版本、镜像版本（当前支持Gradio、Streamlit接入SDK）。 **用户无需修改任何创空间代码**，即可使用xGPU部署您的创空间。为达到最佳的使用体验，建议您使用最新版镜像，以及我们提供的Gradio SDK最新版本。

## 快速开始

### 前提条件
Beta测试期间，若您想体验xGPU的资源，请申请加入 [「xGPU乐园」](https://www.modelscope.cn/organization/xGPU-Explorers) 组织，我们会尽快与您取得联系沟通申请结果，请及时查收站内信或邮箱。

### 使用方法
加入「xGPU乐园」组织后，您可以在新建创空间时，或者编辑已有创空间信息页面，通过选择“空间云资源”，来进行xGPU的资源配置。保存配置后重启即可使用xGPU。
![image.png](./_resources/xgpu_config.png)

### 使用限制
Beta测试期间，体验xGPU创空间部署是免费的！但为了避免不必要的资源浪费，我们也设置了对应的使用限制：
- 每个开发者**基于xGPU能够创建的创空间有数量上限**。同时高档的GPU免费使用时长，可能低于相对低档的GPU。建议您在满足代码运行要求的情况下，**基于“够用”的原则来选择xGPU的GPU卡型**。
- 您也可以通过降低每次请求的耗时，以提高请求被调度的成功率。 
- 为了保证使用的公平性，让更多用户来体验创空间应用，每个用户体验xGPU的时长有上限。
- 在低频时段或较少用户访问的情况下，创空间将被自动休眠。
