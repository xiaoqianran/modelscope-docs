# 关于ModelScope的创空间
ModelScope的创空间（Studio），为您提供自由灵活的AI应用展示空间。您可以基于ModelScope平台上模型提供的原子能力，自行搭建与展示不同AI应用，包括自定义的模型输入输出，多模型的组合，以及可视化交互展现形式等等。我们希望在这里，激发AI开发者的创造力与创新性。由创空间为白纸，以模型为颜料，以想象力为画笔，共谱AI应用五彩斑斓的新画卷！

>  **特别说明：** 您可以自由创建多个创空间并分享给您的朋友，但考虑到首页的空间展示质量，您所创建的空间并不会自动进入创空间首页精选列表，如您有意愿申请进入首页列表，非常欢迎与我们取得联系（钉钉群：8010015744，邮箱：contact@modelscope.cn）

## 名词解释
**创空间（Studio）**：ModelScope平台提供的模型应用可视化私域空间与运营阵地，您可以在此基于ModelScope上丰富的模型生态，灵活搭建多种多样的AI应用。

**Gradio**：Gradio提供轻量化的机器学习交互式web页面定制工具，为开发者迅速定制AI应用提供快速上手的脚手架。创空间目前支持通过Gradio来定制围绕ModelScope模型搭建的线上应用。[点击访问Gradio官网](https://gradio.app/) 了解更多

**Streamlit**：Streamlit相较Gradio更为高阶，Streamlit官方提供了更为丰富的示例与交互模板，支持MarkDown与HTML的渲染。创空间目前支持通过Streamlit来定制围绕ModelScope模型搭建的线上应用。[点击访问Streamlit官网](https://streamlit.io/) 了解更多

**Static**：ModelScope平台预置的HTML Static SDK，支持快速将已有HTML页面展示在您的项目空间中，适合重交互与视觉体验的算法Demo展示。

## 创空间与模型库中在线体验的差别
创空间并不仅仅可用于展示单一模型的体验展示，由于创空间的搭建并不需要太多的前端知识，您可以通过平台提供的算法可视化SDK自由搭建页面（当前已支持Gradio、Streamlit和Static SDK，更多可视化配置SDK接入中），所以相对更自由与灵活，它还有更多的功能用途，包括但不限于：

- **单模型的应用搭建**，您可以在这里基于平台提供的模型，搭建特定领域的模型应用，例如通过人体检测模型搭建跳绳计数应用、通过文本向量模型搭建文本相似度应用等
- **多模型组合应用的展示**，在同一空间展示多个相关模型，例如在同一空间展示素描、3D、艺术、手绘等风格的人像卡通化模型展示，让访问用户在同一页面中快速、便捷的体验多个同类模型
- **复杂入参模型应用展示**，某些模型会有较多的入参信息填写，在模型体验中会较难展开，您可以在这里一展身手，例如AI作画中的图片尺寸、语种、生成图片数量、图片宽高比等多个入参信息的配置
- 更多创意使用等您共同创造……

我们希望在这里，基于大家的想象力与创造力，可以涌现出更多优质、有趣、精彩的空间展示！
