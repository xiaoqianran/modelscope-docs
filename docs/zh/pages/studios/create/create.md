# 创空间创建方式介绍
当前魔搭社区主要提供“编程式创建”、“交互式创建”两种创建创空间的方式，而“编程式创建”提供”自定义创建“及”快速创建并部署“两种模式，可在顶部标题栏快速切换。

- 自定义创建：面向有一定编程经验的用户，支持先创建空仓库、再通过Git等方式将代码项目提交至创空间部署；
- ”快速创建并部署“：面向AI编程用户，提供将复杂配置脚本化的部署方案，支持在创建时上传整个项目代码文件夹并直接触发部署。该模式当前正在Beta测试中，后续我们将持续引入AI辅助能力、简化部署体验。

下文主要介绍“编程式创建”中的自定义创建模式，了解如何”快速创建并部署“可前往 [相关文档](./快速创建并部署.md)获取详细指引。

# 创建自己的创空间

## 前置依赖
1. 请先在魔搭社完成账号注册并登录。
2. 确认您的设备已经安装好 `Git` 和 `Git LFS`.

## 创空间创建步骤
编程式创建主要分为四个步骤： 
- 使用站点页面创建创空间
- 创空间开发
- 上传创空间项目文件
- 部署创空间

接下来我们将逐个介绍每个步骤的操作指南。

### 步骤一：使用站点页面创建创空间
您可以通过 ModelScope 站点页面创建创空间，您有两种方式开始创建创空间：
1. 注册登录后，点击站点任意页面右上角头像，打开下拉菜单点击”创建创空间“，即可进入创建流程。
2. 通过站点页面顶部导航栏进入[创空间首页](https://modelscope.cn/studios),点击页面顶部“我要创建”进入创建流程。

#### 填写基础信息并完成创建
基础信息包括您的模型英文名称、中文名、所有者、许可证类型、是否公开和创空间描述等。
  - License：开源许可证，决定您的创空间遵循对应的开源协议。
  - 是否公开：决定您的创空间是否能被其他用户检索查看，若设置为非公开创空间，则其他用户无法查看，仅您自己查看。您也可以创建后在设置页面进行权限的修改配置。
  - 创空间描述：建议介绍该创空间的特性和应用场景，将展现在创空间相关页面，方便用户了解和搜索查询。
  - 接入SDK：当前开放支持Gradio、Streamlit、Static、Docker等多种框架的应用部署运行，您可以根据实际需求选用。
  - 关联云资源：提供了不同型号的CPU/GPU云资源，包括免费可用的 CPU 云资源、xGPU云资源和付费可用、更高配置的CPU、GPU云资源，您可以根据待部署的应用实际需求灵活选用。
  - 镜像版本：提供了不同系统版本、Python版本、Pytorch版本、modelscope主库版本的镜像文件，如无特殊依赖推荐使用默认选中的最新镜像，您也可以根据待部署应用的实际依赖灵活选用。

基础信息填写完毕后，点击“创建创空间”即可提交创建，这里通常需要花费一点时间，请稍等片刻。

### 步骤二：创空间开发
> 如您已经遵照相关文档完成创空间的开发并准备好相关项目文件，可跳过此步骤

创空间运行的关键文件：
- 启动文件：创空间部署及运行需要指定的启动脚本，若SDK为Gradio/Streamlit，默认为app.py, 若为Static HTML, 默认为index.html，您也可以在创空间卡片（README.md)YAML头的`entry_file`字段修改。
- requirements.txt：需要提前自定义安装的Python依赖列表。在文件中逐行添加依赖即可，示例如下：
  ```shell
  wget
  openssl
  ```
  备注：创空间默认已安装Notebook环境下所有依赖，用户无需额外安装，同时创空间默认安装了Gradio。

- packages.txt：如 Gradio/Streamlit 应用依赖系统级软件包（如 `ffmpeg`、`libsm6`、`cmake` 等），可在仓库根目录添加 `packages.txt` 文件。在文件中逐行添加 Debian/Ubuntu 软件包名，支持空行和以 `#` 开头的注释行，示例如下：
  ```text
  # 视频处理依赖
  ffmpeg

  # 图像处理依赖
  libsm6
  cmake
  ```
  部署时，平台会先安装 `packages.txt` 中声明的系统依赖，再安装 `requirements.txt` 中的 Python 依赖。请仅填写软件包名，不要填写安装命令；如包名不存在或安装失败，可在部署日志中查看错误信息。

- README.md：创空间卡片，是每个创空间都必须包含的文件，具体含义见创空间卡片章节。

创空间项目的具体开发请参考对应SDK框架的开发文档：

#### Gradio
- 官方教程：[https://gradio.app/quickstart/](https://gradio.app/quickstart/)
- 更多示例：[https://gradio.app/demos/](https://gradio.app/demos/)

#### Streamlit
- 官方教程：[https://docs.streamlit.io/](https://docs.streamlit.io/)

### 步骤三：上传创空间项目文件
在站点页面完成创空间创建后，平台将为该创空间分配一个 Git 存储地址，可在“创空间详情-空间内容”页面获取。示例如下：

 ![image.png](./_resources/pre-studio-card.png)

您可使用 Git 方式将文件上传至该创空间仓库中，也可通过页面上传相关文件。

1. 使用git方式添加创空间文件
```bash
git lfs install
#根据实际情况填写
git clone http://oauth2:<your_access_token>@www.modelscope.cn/studios/<your_studio_path>/<your_studio_name>.git

#创建 app.py后添加到git仓库
git add app.py
git commit -m "add app.py"
git push
```
>  其中ACCESS_TOKEN可以通过用账号密码登录网站, 前往[【个人中心】->【访问令牌】](https://modelscope.cn/my/myaccesstoken)获取。


2. 使用站点页面添加创空间文件
您也可以前往“创空间详情页-空间文件”页面，点击“添加文件”按钮，选择“上传文件”或“创建新文件”从本地提交您的项目文件。

### 步骤四：部署创空间
您可以在“创空间详情页-设置”页面中，对您的创空间进行基础设置与部署。

#### 创空间上线
- 当创空间项目文件上传到仓库中后，您需要手动“上线”您的创空间。您可以在空间内容页面看到“立即发布”按钮，也可以在设置页面右侧的“创空间管理”板块您可以很容易的找到“上线”按钮。

- 点击“立即发布”或“上线”按钮，均会立即触发对该空间的部署并发布上线。这个过程将会花费一点时间，请您稍等片刻再来查看。

- 待上线完成后，空间内容中将展示应用页面。

- 若上线部署失败，则可通过官方答疑群联系我们获取帮助。

#### 其他设置项
- **下线**：若创空间不再使用，则可以点击设置页“下线”按钮操作下线。
- **重启创空间**：当创空间代码更新后，可直接点击“设置页-重启创空间”按钮进行重新发布上线，系统将会拉取最新的创空间文件进行部署，部署后“空间内容”页面将展示最新的效果。
- **环境变量管理**：创空间支持新建环境变量，以存储您不便在创空间项目代码文件中明文写入的隐私字段，如API密钥或令牌等等。请注意环境变量添加保存后，不支持查询变量值
  ![image](./_resources/env_variable.png)
  - 请注意：环境变量创建或更新后，须重启创空间方可生效。
  - 使用方式：
    ```python
    import os
    #获取对应环境变量的值, 上面图中的变量名称需要和这里的入参保持一致
    app_key = os.getenv('AppKey')
    # 使用app_key进行后续操作
    ```

## 数据持久化
每次创空间重启时，磁盘上默认写入的数据都会丢失。如果需要持久化存储，您可以使用 /mnt/workspace 目录来存储数据。该目录挂载在一个持久化卷上，这意味着写入此目录的数据将在重启后保留，但是当用户转移、重命名创空间时数据仍会丢失，如有较高需求，建议在 创空间代码中使用外部存储解决方案，例如阿里云OSS存储、托管数据库等。
