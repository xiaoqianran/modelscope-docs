ModelScope 平台为用户部署创空间提供多种不同规格的资源支持。

# 免费资源
针对使用创空间的每位新用户，ModelScope 提供基础的 CPU 机器（2v CPU/16GB），用于运行用户部署到创空间的应用代码。

## 注意事项

- 该免费资源归属于用户，请勿使用算力资源进行违法操作。
- 若实例一段时间未使用后，将进入休眠，重新访问后即会激活启动。
- 后续 ModelScope 社区将推出更多活动，可免费获取 GPU 算力资源，敬请期待。


# 升级资源

## 注意事项
- 服务创建后即按时计费，可按需配置休眠时间，休眠期间不计费。
- 创建后，可在创空间的设置页更换资源规格。
- 若设置为公开创空间，则任何用户的访问行为都将保持或触发创空间上线运行并产生费用。
