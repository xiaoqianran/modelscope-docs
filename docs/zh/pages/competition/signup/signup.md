# 比赛报名

在【动态】-【竞赛】中找到ModelScope社区中的相关竞赛信息。在竞赛列表页查找关注的竞赛，并点击详情查看具体的竞赛内容。

## 赛事报名
![image.png](https://intranetproxy.alipay.com/skylark/lark/0/2022/png/29482/1670206270916-bf0cfcf2-5f23-4e89-8207-560bbc2b910d.png#clientId=u3f744faa-3c7c-4&crop=0&crop=0&crop=1&crop=1&from=paste&height=1362&id=u27060fd5&margin=%5Bobject%20Object%5D&name=image.png&originHeight=1362&originWidth=2826&originalType=binary&ratio=1&rotation=0&showTitle=false&size=2215582&status=done&style=none&taskId=ubb29b9ec-c754-4e27-b82d-108b1d10d6d&title=&width=2826)

报名需要先登录，若您还没有ModelScope社区账号，需要先注册账号后登录。新注册用户限时赠送一定额度的免费GPU算力（具体请参见Notebook[文档](../../notebook/intro/intro_CN.md)），为您的竞赛提供更多资源支持！
![image.png](https://intranetproxy.alipay.com/skylark/lark/0/2022/png/29482/1670206315362-d67fa032-7005-483a-8ab0-82fe119a5c91.png#clientId=u3f744faa-3c7c-4&crop=0&crop=0&crop=1&crop=1&from=paste&height=1342&id=uf4438723&margin=%5Bobject%20Object%5D&name=image.png&originHeight=1342&originWidth=2674&originalType=binary&ratio=1&rotation=0&showTitle=false&size=2296605&status=done&style=none&taskId=uad873f50-16f1-43d8-b9db-6b384428134&title=&width=2674)

登录ModelScope平台后，再次点击“立即报名”，需要您提交可用的邮箱地址，方便赛事主办方通过邮件的形式联系到您。请务必确保您的邮箱地址填写正确。所属组织为您所代替的组织机构或企业，将在排行榜中展示。
在报名前，请确保您已仔细阅读并理解《[参赛者协议](https://modelscope.cn/protocol/%E5%8F%82%E8%B5%9B%E8%80%85%E5%8D%8F%E8%AE%AE)》

![image.png](https://intranetproxy.alipay.com/skylark/lark/0/2022/png/29482/1670206413867-70b8070d-a483-451b-9053-1ec6462af434.png#clientId=u3f744faa-3c7c-4&crop=0&crop=0&crop=1&crop=1&from=paste&height=960&id=uf8fab282&margin=%5Bobject%20Object%5D&name=image.png&originHeight=960&originWidth=1526&originalType=binary&ratio=1&rotation=0&showTitle=false&size=690163&status=done&style=none&taskId=udf460912-d4bf-46da-a56e-0ea71ba2141&title=&width=1526)
![image.png](https://intranetproxy.alipay.com/skylark/lark/0/2022/png/29482/1670206856578-0d541bfe-6a8e-46cc-aba4-7438de86b9b8.png#clientId=u3f744faa-3c7c-4&crop=0&crop=0&crop=1&crop=1&from=paste&height=778&id=ufe91b865&margin=%5Bobject%20Object%5D&name=image.png&originHeight=778&originWidth=1340&originalType=binary&ratio=1&rotation=0&showTitle=false&size=414503&status=done&style=none&taskId=udd9347ff-c64a-42ff-a363-ac2a777cd57&title=&width=1340)

正确填写邮箱地址和组织之后，即可成功报名。此时，您可以选择组队参赛或者暂不组队，以个人方式参赛。需要说明的是：在提交比赛结果前，您都可以自由组队，但当成果提交后，您的成员信息将锁定，不允许比赛过程中再变更队员信息。建议在赛前可以邀请小伙伴一起参赛，确认好成员名单。
## 组件队伍
若选择我要组队，可点击“我要组队”按钮，并确认您的队名。

![image.png](https://intranetproxy.alipay.com/skylark/lark/0/2022/png/29482/1670206793509-660b65f2-7b20-4072-8107-a278cf12563e.png#clientId=u3f744faa-3c7c-4&crop=0&crop=0&crop=1&crop=1&from=paste&height=1178&id=u73682ce2&margin=%5Bobject%20Object%5D&name=image.png&originHeight=1178&originWidth=2214&originalType=binary&ratio=1&rotation=0&showTitle=false&size=1079191&status=done&style=none&taskId=ue42ce22f-1ce6-4c11-9653-7947947db18&title=&width=2214)

注意，因不同的比赛有队伍参赛人数限制，请确保您的队伍不会超过上限。点击“添加队员”，输入队员的用户名即可添加成功。（用户名是队员的登录名，在网站右上角可查看）

![image.png](https://intranetproxy.alipay.com/skylark/lark/0/2022/png/29482/1670207016977-b8696478-a081-4152-b8cc-ecba787f9b90.png#clientId=u3f744faa-3c7c-4&crop=0&crop=0&crop=1&crop=1&from=paste&height=1278&id=uaad6e9e9&margin=%5Bobject%20Object%5D&name=image.png&originHeight=1278&originWidth=2402&originalType=binary&ratio=1&rotation=0&showTitle=false&size=1110786&status=done&style=none&taskId=u6e726a2d-1a63-4699-9baf-4506cfecf1f&title=&width=2402)
![image.png](https://intranetproxy.alipay.com/skylark/lark/0/2022/png/29482/1670207250059-13a37cd9-f56b-4f98-8960-6803c3f2b926.png#clientId=u3f744faa-3c7c-4&crop=0&crop=0&crop=1&crop=1&from=paste&height=1360&id=ua3479c58&margin=%5Bobject%20Object%5D&name=image.png&originHeight=1360&originWidth=2824&originalType=binary&ratio=1&rotation=0&showTitle=false&size=2034245&status=done&style=none&taskId=u82ea84cf-3c5e-4002-aced-dfe7ec7f315&title=&width=2824)

因比赛要求每位参赛用户都提供有效邮箱，因此所邀请的队员也必须先报名后才能组队。请确保你邀请的队员也完成了“立即报名”的操作。否则将出现如下错误提示。

![image.png](https://intranetproxy.alipay.com/skylark/lark/0/2022/png/29482/1670207336621-69dc47f8-7ad5-4eea-92e3-cff0bb26aba0.png#clientId=u3f744faa-3c7c-4&crop=0&crop=0&crop=1&crop=1&from=paste&height=918&id=ud5c9a13b&margin=%5Bobject%20Object%5D&name=image.png&originHeight=918&originWidth=1388&originalType=binary&ratio=1&rotation=0&showTitle=false&size=564336&status=done&style=none&taskId=u1b5e5389-2987-4900-8eeb-71a0cd1c261&title=&width=1388)

若对方也成功报名，此处输入队员的用户名，即可添加成功。（本期队长可以增加或删除队员，队员暂时不可自主退组，请确保线下沟通好后再组队参赛）

![image.png](https://intranetproxy.alipay.com/skylark/lark/0/2022/png/29482/1670211033638-8622e8de-52e3-4692-80a7-cc799dfa1adb.png#clientId=ua070116f-fe12-4&crop=0&crop=0&crop=1&crop=1&from=paste&height=561&id=u178d7d8c&margin=%5Bobject%20Object%5D&name=image.png&originHeight=1122&originWidth=1982&originalType=binary&ratio=1&rotation=0&showTitle=false&size=1009962&status=done&style=none&taskId=u51dd8d10-cc29-48b2-862d-a7e86ab92ea&title=&width=991)

组队成功后可在“我的队伍/成绩”页面编辑队员信息，也可在该页面查看提交结果。

成功报名后，页面上将出现Notebook的入口，ModelScope平台为各位参赛选手提供了免费的在线资源环境，我们也鼓励参赛选手使用Notebook实现模型训练等开发操作。

在提交结果时间开始之前，您都可以下载数据集进行调试，在开始提交结果后不再允许团队变动，感谢您的配合与理解。
## 解散队伍
在提交结果前，若您不想再组队，需要由队长发起解散组队。解散组队后队员将恢复单人参赛模式，可再重新组队。

![image.png](https://intranetproxy.alipay.com/skylark/lark/0/2022/png/29482/1670210571479-ecdeb62a-b44d-497e-957c-4d61feceeff7.png#clientId=ua070116f-fe12-4&crop=0&crop=0&crop=1&crop=1&from=paste&height=671&id=u0b50fd13&margin=%5Bobject%20Object%5D&name=image.png&originHeight=1342&originWidth=2746&originalType=binary&ratio=1&rotation=0&showTitle=false&size=1218085&status=done&style=none&taskId=udf2fab89-2c16-4b70-9e7b-31b6ffe7e17&title=&width=1373)

在相同比赛中，一个选手不可参加多个队伍，若不想继续参加这个队伍可告知队长，由队长手动移除队员。
