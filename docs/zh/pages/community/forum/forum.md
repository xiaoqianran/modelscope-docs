# 开发者论坛

ModelScope提供了阿里云开发者社区官方子社区，团队会定期发布关于产品的最新资讯、学习路径、技术交流等，详情请关注：[**ModelScope社区**](https://developer.aliyun.com/space/modelscope/)
<br/>ModelScope按照技术领域下设5个板块，分别为[**计算机视觉**](https://developer.aliyun.com/space/modelscope/cv) 、[**语音**](https://developer.aliyun.com/space/modelscope/speech) 、[**自然语言处理**](https://developer.aliyun.com/space/modelscope/nlp) 、[**多模态**](https://developer.aliyun.com/space/modelscope/multimodal) 、[**科学计算**](https://developer.aliyun.com/space/modelscope/scientific-computing) ，可根据您关注的模型类型选择板块进行发帖和互动。
- 计算机视觉/语音/自然语言处理/多模态/科学计算：支持不同技术领域的ModelScope模型/数据集/创空间使用问题讨论，并提供模型使用教程、活动资讯、官方博客等信息。

ModelScope的library目前也已经在GitHub内开源，欢迎开发者下载使用和二次开发 [**ModelScope开源地址**](https://github.com/modelscope/modelscope)
