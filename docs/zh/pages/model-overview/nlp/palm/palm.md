# 模型概览

文本生成预训练模型是目前解决文本生成任务常采用的模型，通过大量无监督文本训练得到的文本生成预训练模型，在下游的文本生成任务上提升明显。而现有的文本生成预训练模型大部分还是在生成decoder侧去引入任务训练，忽略了encoder端理解能力训练的重要性。针对这一问题，提出了[PALM](https://aclanthology.org/2020.emnlp-main.700)预训练生成模型，模型结合了自编码和自回归预训练，自回归生成文本建立在自编码预训练得到的双向理解文本的基础上，通过大量的无监督数据训练得到，模型有中、英不同版本，同时也有不同参数size的模型。模型结构见下图

![model](./_resources/palm.png)

关于该模型更多细节介绍可以前往论文了解，论文的摘要信息如下：

```text
自监督预训练，如 BERT、MASS 和 BART，已经成为一种强大的自然语言理解和生成技术。现有的预训练技术采用自动编码和/或自回归目标来训练基于 Transformer 的模型，方法是从带有一些掩码标记的损坏文本中恢复原始单词标记。现有技术的训练目标通常与许多语言生成任务的目标不一致，例如生成式问答和对话回复生成，以在给定上下文的情况下生成新文本。我们提出PALM模型，在大规模未标记语料库上联合预训练自编码和自回归语言模型，专门用于生成以上下文为条件的任务场景。PALM 缓解了现有去噪方案在预训练和微调之间引入的不匹配，其中生成不仅仅是重建原始文本。一组广泛的实验表明，PALM 在EMNLP论文发表时各种语言生成基准上取得了新的最先进的结果，包括生成式问答（在官方 MARCO 排行榜上排名第一）、CNN/DailyMail 和 Gigaword 生成摘要任务， SQuAD 上的问题生成。
```

模型领先性：

    1. PALM模型结合了自编码和自回归预训练，Encoder：引入自编码的预训练增强encoder对输入文本的上下文理解能力，Decoder：引入自回归任务，基于encoder对输入上下文理解来生成
    2. 利用大量中文和英文的无监督语料训练得到了中、英不同版本，同时也有不同参数size的模型。
    3. 模型在英文生成式问答（在官方 MARCO 排行榜上排名第一）、CNN/DailyMail 和 Gigaword 生成摘要等任务上都取得SOTA的结果，在中文生成数据上，如LCSTS摘要生成，ADGEN生成和CSL生成上都取得了高于中文BART、T5等SOTA模型



# 模型配置项

PALM模型的超参数控制可以在下载下来的模型文件中找到config.json文件，该文件一般格式如下：

```text
{
  "encoder": "roberta",
  "encoder_pth": "roberta-base",
  "max_pos": 512,
  "share_emb": false,
  "dec_layers": 12,
  "dec_hidden_size": 768,
  "dec_heads": 8,
  "dec_ff_size": 3072,
  "dec_dropout": 0.2,
  "use_bert_emb": true,
  "label_smoothing": 0.1,
  "alpha": 0.95,
  "beam_size": 5,
  "min_length": 40,
  "max_length": 130
}
```
在预训练模型中，这些配置只是模型全部配置中的一部分。PALM的模型参数会通过PalmConfig类传入，下面是API文档中列举的常用的配置项：

## 参数列表


* **encoder** (`str`, optional, defaults to "roberta") - PALM is an encoder-decoder model, and the encoder will be constructed according to the config.json file, which can accept "zh_bert" or "roberta".


* **encoder_pth** (`str`, optional, defaults to "roberta-base") - The necessary parameters and tokenizer of the encoder need to be readable under the model path. This parameter is the path name, usually including files such as config.json and vocab.json.


* **max_pos** (`int`, optional, defaults to 512) – The maximum sequence length that this model might ever be used with. Typically set this to something large
just in case (e.g., 512 or 1024 or 2048).


* **share_emb** (`bool`, optional, defaults to false) - Whether to share the parameters of the embedding layer between the encoder and decoder.


* **dec_layers** (`int`, optional, defaults to 12) – Number of hidden layers in the Transformer decoder.


* **dec_hidden_size** (`int`, optional, defaults to 768) – Dimensionality of the decoder layers and the pooler layer.


* **dec_heads** (`int`, optional, defaults to 8) – Number of attention heads for each attention layer in the Transformer decoder.


* **dec_ff_size** (`int`, optional, defaults to 3072) – Dimensionality of the “intermediate” (often named feed-forward) layer in the Transformer decoder.


* **dec_dropout** (`float`, optional, defaults to 0.2) – The dropout probability for all fully connected layers in the embeddings, decoder, and pooler.


* **use_bert_emb** (`bool`, optional, defaults to true) - Whether to use the same embedding layer in the decoder as the Bert model.


* **label_smoothing** (`float`, optional, defaults to 0.1) - Softening the ground-truth labels in the training data in an attempt to penalize overconfident outputs.


* **alpha** (`float`, optional, defaults to 0.95) - The length penalty for beam search geneartion.


* **beam_size** (`int`, optional, defaults to 5) - The parameter in the beam search algorithm which determines how many of the best partial solutions to evaluate.


* **min_length** (`int`, optional, defaults to 40) - Minimum length of token generated by the generator.


* **max_length** (`int`, optional, defaults to 130) - Maximum length of token generated by the generator.

当用户在推理中使用PALM的模型时，这些参数一般都是固定的。您可以使用Model类直接拉起模型：
```python
from modelscope.models import Model
model = Model.from_pretrained('damo/nlp_palm2.0_text-generation_chinese-base')
```

如果您使用ModelScope的trainer进行训练，ModelScope推荐您在trainer中对模型参数等进行配置和调节。训练过程可以参考下文“模型的训练”。

# 模型前处理

## tokenizer

PALM模型支持中英文，根据语言使用不同的tokenizer，英文模型使用RobertaTokenizer，中文模型使用BertTokenizer。如果您需要在外部框架中直接使用PALM，可以使用transformers库中的tokenizer，以英文PALM模型为例：

```python
from transformers import RobertaTokenizer
# encoder_pth 与模型配置中的对应参数意义相同
tokenizer = RobertaTokenizer.from_pretrained(encoder_pth)
output = tokenizer('This is a test.', return_tensors='pt')
print(output)
# 将tokenizer的输出传入模型
print(model(**output))
```

Tokenizer的实现和使用可以查看huggingface的tokenizer文档：[BertTokenizer](https://huggingface.co/docs/transformers/model_doc/bert#transformers.BertTokenizer) 和 [RobertaTokenizer](https://huggingface.co/docs/transformers/model_doc/roberta#transformers.RobertaTokenizer)。

## 前处理器（Preprocessor）

如果您在ModelScope框架中使用PALM，ModelScope建议您使用前处理器而非直接调用tokenizer。
ModelScope的前处理器对各类任务进行了特化封装，并直接对接数据集模块（前处理器承载了取数据、tokenize数据、tensor化、分析label等功能），因此您不需要在直接调用tokenizer并为每个任务编写不同的适配代码。

在ModelScope框架中，PALM对应文本生成任务，可以使用文本生成任务的前处理器：

```python
from modelscope.hub.snapshot_download import snapshot_download
from modelscope.preprocessors import TextGenerationTransformersPreprocessor

model_id = 'damo/nlp_palm2.0_text-generation_english-base'
model_dir = snapshot_download(model_id)
sentence = 'This is a test.'

preprocessor = TextGenerationTransformersPreprocessor(model_dir, padding=False)
# 前处理器可以通过__call__方法直接使用
result = preprocessor(sentence)
print(result)
```

构造参数:


* **model_dir** (`str`) – The model_dir to load the configuration from. Note that this model_dir must exist in the local file system.

* **mode** (`str`, optional, defaults to ‘inference’) – The work mode for this preprocessor. Valid values can be ‘train’, ‘eval’ and ‘inference’.
This preprocessor’s behavior may be different under these values.

* **kwargs** (`dict`, optional) 
    
    sequence_length: The input sequence length to padding to.

    first_sequence: The key for the first sequence

    second_sequence: The key for the second sequence

    label: The label key

    label2id: An optional label2id mapping, the class will try to call utils.parse_label_mapping if this mapping is not supplied.

    Other input args will be fed into the tokenizer at the runtime.

前处理器可接受的参数类型有str、tuple、dict。当用户的输入是tuple或str时，构造时传入的first_sequence、second_sequence、label三个参数不起作用。

有关Preprocessor的整体使用可以参考[这里](https://www.modelscope.cn/docs/%E6%95%B0%E6%8D%AE%E7%9A%84%E9%A2%84%E5%A4%84%E7%90%86)。

# 模型支持的下游任务

## 文本生成任务

NLP中的文本生成任务又可以分为许多具体任务，如文本摘要，机器翻译、故事续写等。这些任务在modelhub中有不同的模型可以使用，部分任务之间可以复用模型和前处理器。

### 文本生成任务的模型

PALM的PalmForTextGeneration类可以将文本摘要或其他具体任务模型加载起来用于训练和推理。

```python
from modelscope.models.nlp import PalmForTextGeneration
# 加载摘要生成模型
model = PalmForTextGeneration.from_pretrained('damo/nlp_palm2.0_text-generation_chinese-base')
# 加载商品文案生成模型
model = PalmForTextGeneration.from_pretrained('damo/nlp_palm2.0_text-generation_commodity_chinese-base')
# 加载天气播报模型
model = PalmForTextGeneration.from_pretrained('damo/nlp_palm2.0_text-generation_weather_chinese-base')
```

#### 模型forward参数

    
* **input_ids** (`torch.LongTensor` of shape `(batch_size, sequence_length)`) – Indices of input sequence tokens in the vocabulary.

* **attention_mask** (`torch.FloatTensor` of shape `(batch_size, sequence_length)`, optional) – Mask to avoid performing attention on padding token indices. Mask values selected in `[0, 1]`:


    1 for tokens that are **not masked**,


    0 for tokens that are **masked**.

* **labels** (`torch.LongTensor` of shape `(batch_size, sequence_length)`) - Indices of input sequence tokens in the vocabulary for calculating loss.

#### 模型generate参数

* **input_ids** (`torch.LongTensor` of shape `(batch_size, sequence_length)`) – Indices of input sequence tokens in the vocabulary.

* **attention_mask** (`torch.FloatTensor` of shape `(batch_size, sequence_length)`, optional) – Mask to avoid performing attention on padding token indices. Mask values selected in `[0, 1]`:


    1 for tokens that are **not masked**,


    0 for tokens that are **masked**.

### 文本生成任务的Pipeline

如果用户的场景是推理，ModelScope推荐您直接使用pipeline来完成您的需求。

```python
from modelscope.pipelines import pipeline
from modelscope.utils.constant import Tasks
from modelscope.outputs import OutputKeys

input = '昨天起，上海地铁3号线长江南路站、殷高西路站、江湾镇站三站进一步限流。体验发现，高峰时段排队5分钟能进站；不少乘客选择提前起床，“现在提前10到20分钟起床，即便限流也不会影响上班”。被限流的XDJMS，你们提前多久？新民网'
text_summary = pipeline(Tasks.text_generation, model='damo/nlp_palm2.0_text-generation_chinese-base')
result = text_summary(input)

print('输入文本:\n' + input + '\n')
print('文本摘要结果:\n' + result[OutputKeys.TEXT])
```

有关pipeline的使用和它们的输出格式请参考[这里](https://www.modelscope.cn/docs/%E6%A8%A1%E5%9E%8B%E7%9A%84%E6%8E%A8%E7%90%86Pipeline)。

### 文本生成任务模型的导出

如果您是在C++或加速场景下使用StructBERT，您也可以将模型导出为onnx或TorchScript格式。

```python
from modelscope.models import Model
model = Model.from_pretrained('damo/nlp_palm2.0_text-generation_chinese-base')
# 由于TorchScript是Pytorch特有的格式，因此需要使用TorchModelExporter
from modelscope.exporters import TorchModelExporter
# shape参数是生成dummy inputs的尺寸
# 在NLP领域中一般len(shape) == 2, 分别代表batch_size和sequence_length
output_files = TorchModelExporter.from_model(model).export_torch_script(shape=(2, 256), outputs='/tmp')
print(output_files) # {'model': '/tmp/model.ts'}
```

上面给出了一个导出为TorchScript的例子。在这一过程中，ModelScope会使用模型配置来初始化一个预处理器并生成dummy inputs，并使用trace方法来生成ts模型文件。
有关模型导出的具体细节可以参考[模型的导出](https://modelscope.cn/docs/%E6%A8%A1%E5%9E%8B%E7%9A%84%E5%AF%BC%E5%87%BA)。

# 模型的训练

PALM模型的训练可以使用ModelScope提供的trainer来进行。下面的代码展示了一个完整的模型训练过程：
```python
from modelscope.msdatasets import MsDataset
from modelscope.trainers import build_trainer
from modelscope.metainfo import Trainers

import tempfile

# 使用 DuReader_robust-QG 数据集进行训练
dataset_dict = MsDataset.load('DuReader_robust-QG')
# 重命名数据集字段使于模型输入匹配
train_dataset = dataset_dict['train'].to_hf_dataset() \
    .rename_columns({'text1': 'src_txt', 'text2': 'tgt_txt'})
eval_dataset = dataset_dict['validation'].to_hf_dataset() \
    .rename_columns({'text1': 'src_txt', 'text2': 'tgt_txt'})
tmp_dir = tempfile.TemporaryDirectory().name

# 可在代码中自定义 lr_scheduler 方法
num_warmup_steps = 200
def noam_lambda(current_step: int):
    current_step += 1
    return min(current_step**(-0.5),
               current_step * num_warmup_steps**(-1.5))

# cfg_modify_fn 可对训练配置进行修改
def cfg_modify_fn(cfg):
    cfg.train.lr_scheduler = {
        'type': 'LambdaLR',
        'lr_lambda': noam_lambda,
        'options': {
            'by_epoch': False
        }
    }
    return cfg

kwargs = dict(
    model='damo/nlp_palm2.0_pretrained_chinese-base',
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    work_dir=tmp_dir,
    cfg_modify_fn=cfg_modify_fn)

# 构造 trainer 并进行训练
trainer = build_trainer(
    name=Trainers.nlp_base_trainer, default_args=kwargs)
trainer.train()
```
推荐基于预训练模型damo/nlp_palm2.0_pretrained_chinese-base这一checkpoint进行训练。训练后再work_dir中会存储训练过程文件（用于断点继续训练）和推理文件（用于上传modelhub或推理、导出等场景）。
训练的具体细节和产出文件的使用请参考[模型的训练文档](https://www.modelscope.cn/docs/%E6%A8%A1%E5%9E%8B%E7%9A%84%E8%AE%AD%E7%BB%83Train)。
