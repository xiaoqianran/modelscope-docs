本篇文章向您详细介绍数据集的文件维护功能及注意事项，数据集创建请参考[数据集介绍](./数据集介绍.md)中创建数据集部分。

# 核心概念
- 【预发布】为了保障平台内的数据集质量，我们针对所有贡献者的数据集，引入了文件审核机制。目前该审核机制会校验以下几种情况，如果命中了任意一种，则该数据集被标记为预发布状态：
    - 英文名包含且只含"test"。
    - 中文名字包含且只含"test"， 中文名字包含且只含"测试"二字。
    - 数据集当中只有以下几种文件：
        - README.md
        - dataset_infos.json
        - 数据集同名 json 文件或空的数据集同名 Python 文件，注意：如果Python文件不为空，则可以脱离预发布状态

    在您已经将数据集文件上传到hub中，且您上传的数据集没有满足以上条件，我们将自动为您的数据集标记为**预发布（preview）状态**，预发布状态下，**该资源不支持列表页展示及搜索**。我们鼓励更多开发者在ModelScope社区内分享数据集，同时也希望能够和开发者一起完善数据集的质量。

- 【数据集文件】实际的数据文件，支持多种格式和组织方式
  - 支持单文件，包括csv、json、jsonl、txt、parquet等格式
  - 支持多文件组织，包括文件夹、多文件压缩包等
  - 数据集同名Python文件，用于指定数据集的组织和加载形式

# 数据集维护
![image.png](./_resources/1659854600601-8780585c-f957-4bb9-a72c-55e581ce7521.png)
数据集介绍内容由元数据文件中的README.md文件解析生成。为方便用户使用，建议包含数据集描述、简介、数据格式、数据集加载方式、数据集版权、引用方式等内容。

为方便维护README.md文件，系统提供了对应文件[生成器小工具](https://www.modelscope.cn/#/readmeformatter)，您可以在手工选择后，直接粘贴自动生成的内容到对应编辑窗口，快速生成数据集描述内容。

# 数据预览
![image.png](./_resources/1659854718253-6e385ea5-61cf-4c25-a500-4d32e2c1b57e.png)
可以预览数据集中的数据文件，支持按子数据集、用途，预览前1000条数据。预览内容由系统自动生成。
如未能自动生成预览内容，可能的原因有：

- 数据集正在解析中，尚未生成预览数据；
- 未按规范要求，提供正确的数据集信息，[数据集文件规范](./数据集文件规范.md)；
- 由于网络受限原因，导致系统无法访问托管于公开Host的数据集；
- 托管到ModelScope的数据集，zip包大于等于5GB时，不支持预览功能；


# 拆分数据集
通常一个数据集，想要被很好地使用，需要划分好训练集(train)、验证集(validation)以及测试集(test)这样的用途(split)概念。对于规模很大的数据集，我们还会引入子数据集(subset)的概念，因此一个完备的数据集经过拆分将具备以下三级：
- 命名空间(namespace)/数据集名(name) 
- 子数据集（subset name）
- 用途

一个数据集可以包含多个子数据集，比如一个自然语言处理的训练集可以按语种划分不同的子集。而每个子数据集都可以包含训练、测试以及验证中的一种或多种用途。


# 删除数据集
您只能对自己拥有或管理的数据集进行管理设置操作。请前往至需要删除的数据集卡片，并点击“设置”页面，在这里您可以编辑数据集的中文名称、描述，修改数据集的开源许可证协议或数据集的可见权限。您也可以在此页面删除数据集。

![image.png](./_resources/1660923430468-b8a09d0c-f9d5-4793-9361-025cb81bdbcc.png)

需要注意的是，若您需要删除数据集，需要进行二次验证。且该删除操作不可撤销，数据集中的所有文件将被永久性删除，请谨慎操作！
