# 整体介绍
本指南将详细介绍如何注册成为ModelScope社区的一员，以及如何登录和管理您的个人账户信息。

# 账号注册
### 注册方式
您可通过魔搭主页右上角"登录/注册"按钮进入注册页面
![image.png](./_resources/注册.png)

您需要填写以下注册信息：
- 账号名：设置您想要注册的账号名，6-20个字符，字母或数字，以字母开头。
- 手机号码：输入您的手机号码，确保号码准确无误，以便接收验证码。
- 验证码：点击“发送”按钮后，系统会向您提供的手机号发送一条包含数字验证码的短信。 在指定输入框中正确填写收到的验证码，并确保在有效时间内完成验证。
- 登录密码：为了账户安全，请设置一个强密码，建议包含大小写字母、数字及特殊字符，长度不少于6位。
- 阅读并同意[《ModelScope社区账户服务协议》](https://modelscope.cn/protocol/%E7%94%A8%E6%88%B7%E5%8D%8F%E8%AE%AE%E4%B8%8E%E9%9A%90%E7%A7%81%E6%94%BF%E7%AD%96)

完成上述步骤后，点击“同意并注册”按钮，如果信息无误，系统将提示您注册成功，并自动跳转至登录页面。

# 账号登录
### 账号密码或手机号登录
在登录页面，需要您输入注册时使用的账号或手机号，以及对应的核身信息：
![image.png](./_resources/登录.png)
点击“登录”后，系统将验证您的信息并登录账户。

### 三方登录
为了方便用户，我们也支持通过第三方账户直接登录：

#### CSDN三方登录

点击CSDN图标，按照指引授权即可关联您的CSDN账号登录ModelScope。

#### GitHub三方登录

点击GitHub图标，按照指引授权即可关联您的GitHub账号登录ModelScope。


# 个人中心
一旦账号创建成功并登录后，您可通过[首页](https://modelscope.cn/my/overview) 不同入口进入ModelScope的个人中心。在这里，您可以：

- 查看账号设置：包括用户名、绑定手机号等基本信息。
- 修改账号设置：包括设置个性化头像、设置身份、设置联系邮箱等操作。
- 账户安全管理： 
  - 忘记密码：提供邮箱或手机号找回服务，按指示操作重设密码。 
  - 修改密码：在安全设置中可以随时更改账户密码，增强账户安全性。 
  - 修改绑定手机号：若需更换绑定的手机号，可通过验证原手机号或邮箱后进行修改。
