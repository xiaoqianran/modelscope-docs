本文档旨在引导您完成在ModelScope平台上创建新组织的流程。

# 如何申请与认证
为了确保您的组织创建申请能够顺利进行，请遵循以下指引填写[组织申请表单](https://modelscope.cn/organization/create)

需要填写的信息包括：
   - 组织中文名：组织对外的展示名称，确保其能够准确反映组织的特性和定位。
   - 组织英文名：限英文和数字，不能以数字开头，将用于创建代码仓库
   - 组织类型：可填学校/研究机构/企业
   - 相关链接：欢迎关联组织官方或者您团队GitHub地址等链接
   - 联系方式：后续和您取得联系的方式，可填写邮箱/手机号等联系方式
   - 详细介绍：输入介绍内容方便更多人了解、认识您的组织，支持富文本内容输入。


# 申请成功
若创建组织申请通过，您将收到邮件回复，登录ModelScope账号后可在个人控制台内看到您已创建的组织。
