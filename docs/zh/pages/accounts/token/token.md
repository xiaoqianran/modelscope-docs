在 ModelScope，您可以通过 SDK 和 Git 两种方式访问社区资源。我们提供了统一的访问令牌（Access Token/ModelScope Token）同时用于这两种访问资源的方式，以便社区用户管理和使用。
本文介绍访问令牌的相关操作。

# 访问令牌查询
前往[首页->访问令牌](https://modelscope.cn/my/myaccesstoken)页面即可新建或查询您的访问令牌。
![image.png](./_resources/accesstoken.png)

# 访问令牌管理
- **访问令牌的新建**：首次使用访问令牌，您需要手动新建，并为该令牌指定合适的有效期，包括“长期使用”或“短期使用”两种。其中，短期使用允许您按月为单位定制有效时长，您可以根据实际使用场景灵活设置。

- **允许创建的访问令牌数量**：您可以创建多个不同名称、不同有效期的令牌，当前生效中的访问令牌数量最多不超过 10 个。

- **访问令牌的删除**：对于任何一个访问令牌，均可进行**删除**。为避免对您正常使用产生影响，进行相关操作后，请确保在所有使用场景中进行更新。

# 使用访问令牌进行 GIT 操作
统一的访问令牌目前已支持 Git 相关操作，用法保持不变，详细请参阅相关站点文档或页面说明。

当需要重置时，请前往[首页->访问令牌](https://modelscope.cn/my/myaccesstoken)分别完成新的访问令牌创建与旧的访问令牌删除。

请注意：一旦删除旧的访问令牌，将会**立即失效**，这可能影响所有访问令牌被使用到的场景，包括模型上传，以及 AIGC 专区的模型训练等。

如您需要更新关联的本地仓库的 remote URL，可参考以下步骤完成更新：
```shell
# 假设您的账户名是`user`，需要更新的模型名称为 `my-test-model`，新访问令牌为`new_access_token`，
git remote set-url origin https://oauth2:new_access_token@modelscope.cn/user/my-test-model.git
```

## Git 访问令牌（已弃用）
- 原 Git 访问令牌不再支持新增，并将逐渐完成下线。
- 在进行 Git 相关操作时，当前您仍然可以使用已经获取的 Git 访问令牌，但社区**不再支持对 Git 访问令牌的查询与重置**。
- **为免影响您的后续使用，请尽快升级至统一访问令牌**。
