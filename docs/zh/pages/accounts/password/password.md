# 密码修改与密码找回

本文介绍账号中心相关功能，包括忘记密码、修改密码、修改绑定手机号等操作。

首先，ModelScope社区的账号注册需要绑定手机号，若您在之前的版本中未绑定手机号，在登录后请根据平台提示完成手机号的绑定。
## 修改密码
点击头像-个人中心<br />![image.png](./_resources/1.png)<br />进入个人中心页面，点击头像上方的编辑按钮，进入账户中心页面。<br />![image.png](./_resources/2.png)<br />点击修改登录密码<br />![image.png](./_resources/3.png)<br />根据页面提示进行身份验证和密码修改。<br />![image.png](./_resources/4.png)

![image.png](./_resources/5.png)<br />成功修改后将自动跳转登录页面进行新用户名密码的登录。<br />![image.png](./_resources/6.png)

## 忘记密码
若您忘记登录密码，可点击登录界面右下角的忘记密码按钮，根据提示重置密码。<br />![image.png](./_resources/7.png)<br />![image.png](./_resources/8.png)<br />输入验证码后重置密码<br />![image.png](./_resources/9.png)

注意，若您的账号未绑定手机号，无法找回密码。建议您重新注册新的账号并绑定手机号。<br />![image.png](./_resources/10.png)
## 修改绑定手机号
若您需要修改绑定手机号，前往**个人中心-账户设置**页面，点击“修改绑定手机号”按钮，并根据提示更改换绑手机。<br />![image.png](./_resources/11.png)<br />注意，换绑手机号需要验证，将向您原来的手机号发送验证码，若成功验证后可换绑新手机。 若您原来的手机号丢失或不可用，则无法验证身份，则此时建议您可联系我们或重新注册新的账号继续使用ModelScope。<br />![image.png](./_resources/12.png)
