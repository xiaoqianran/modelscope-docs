# 前端组件文档

本篇将介绍 widget 配置项中的前端输入输出组件。

> 在下方组件中，数据类型对应推理时的输入或输出值，额外属性则用于定义前端组件的展示效果，对应 widget 中的`displayProps`字段。

## 文本

### 输入组件

#### TextArea

标准的文本输入组件。

##### 数据类型

string

##### 额外属性

| 属性        | 类型                                     | 是否必填 | 描述                                                       |
| ----------- | ---------------------------------------- | -------- | ---------------------------------------------------------- |
| type        | enum 类型，值为 'string' &#124; 'number' | 否       | 默认为`string`，当 type 为`number`时会限制输入只能为数字。 |
| placeholder | string                                   | 否       | 输入框默认占位文本。                                       |
| style       | object                                   | 否       | 配置输入框前端样式。                                       |

#### Input

和 TextArea 类似，但只有一行输入，一般用于输入少量文本。

##### 数据类型

string

##### 额外属性

| 属性        | 类型   | 是否必填 | 描述                 |
| ----------- | ------ | -------- | -------------------- |
| placeholder | string | 否       | 输入框默认占位文本。 |

#### InputList

文本输入框列表，可以设置最小与最大长度，一般和 widget 的`text-list`字段对应，用于任意数量的多行文本。

##### 数据类型

string[]

##### 额外属性

| 属性   | 类型         | 是否必填 | 描述                                             |
| ------ | ------------ | -------- | ------------------------------------------------ |
| addBtn | string、null | 否       | 列表新增按钮的文本，默认值为 `新增`。            |
| min    | number       | 否       | 列表最小长度，默认值为 `1`。                     |
| max    | number       | 否       | 列表最大长度。                                   |
| input  | object       | 否       | 配置`Input`的额外属性，具体属性参考`Input`组件。 |

#### TagInput

文本输入列表，一般和 widget 的`text-list`字段对应，用于任意数量的多行**短文本**，一般于输入文本标签等内容。

##### 数据类型

string[]

##### 额外属性

| 属性        | 类型   | 是否必填 | 描述                 |
| ----------- | ------ | -------- | -------------------- |
| placeholder | string | 否       | 输入框默认占位文本。 |

### 输出组件

#### Text

标准的文本输出组件，传入的内容都会被转为 string，一般用于推理结果为文本的任务类型。

##### 数据类型

string | array | object

##### 额外属性

| 属性        | 类型                                 | 是否必填 | 描述                                                                                                                                                     |
| ----------- | ------------------------------------ | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| arrayParser | enum 类型，值为 'json' &#124; 'text' | 否       | 配置当输出内容为 array 时的展现形式：<br />1. 为 text 时会将数组的值通过 \\n 分割。<br />2. 为 json 时会通过 json 结构展示数组。<br /> 默认值为 `text`。 |
| replaceList | [v1: string, v2: string][]           | 否       | 需要替换的文本对数组，会通过遍历推理结果，用 v2 代替所有 v1 的字符串内容。                                                                               |

#### TextEntity

较为特殊的文本输出组件，一般文本实体类任务使用。

##### 数据类型

{type: string; span: string; start: number; end: number}[]<br />一个文本实体列表，每一项的结构如下：

| 属性  | 类型   | 是否必填 | 描述         |
| ----- | ------ | -------- | ------------ |
| type  | string | 是       | 实体类型     |
| span  | string | 是       | 实体内容     |
| start | number | 是       | 实体开始位置 |
| end   | number | 是       | 实体结束位置 |

#### WordSegmentation

较为特殊的文本输出组件，一般在单词分割类任务使用。

##### 数据类型

string[]

## 图片

### 输入组件

#### ImageUploader

标准的图片上传组件。

##### 数据类型

string

##### 额外属性

| 属性  | 类型   | 是否必填 | 描述                              |
| ----- | ------ | -------- | --------------------------------- |
| label | object | 否       | 配置额外的提示信息。              |
| tips  | string | 否       | `上传图片`按钮的 hover 提示信息。 |

**label**

| 属性      | 类型   | 是否必填 | 描述             |
| --------- | ------ | -------- | ---------------- |
| label     | string | 是       | 提示信息文本。   |
| bgColor   | string | 否       | 提示信息背景色。 |
| textColor | string | 否       | 提示信息文本色。 |

#### ImageCanvas

图像绘制组件，在上传图片的基础上增加了绘制黑白图的功能。<br />**注：** 由于该组件会产生两个输入值，所以需要占用两个 inputs 元素的位置，需要配合`Empty`组件使用。

```yaml
widgets:
  - inputs: # 第一个元素对应上传的图片，第二个字段对应绘制好的黑白图
      - type: image
        displayType: ImageCanvas
      - type: image
        displayType: Empty
```

##### 数据类型

string、string

### 输出组件

#### Image

标准的图像输出组件

##### 数据类型

string

#### ImageList

图像输出列表，用于对应推理返回图片列表的情况。

##### 数据类型

string[]

#### ImageDraw

图像标注组件，用于对参与推理的图像返回对应的标注结果，包含`points、boxes、maskes`等数据。<br />**注：** 当使用该组件时，输入组件必须为`ImageUploader`或`ImageCanvas`。

##### 数据类型

object，字段如下：

| 属性     | 类型                                                                                                | 是否必填 | 描述                                                                                                                                                                               |
| -------- | --------------------------------------------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| boxes    | [x1: number, y1: number, x2: number, y2: number][]                                                  | 否       | 标准四边形坐标点集合，`[x1: number, y1: number, x2: number, y2: number]`代表每个 box 的坐标。                                                                                      |
| points   | [x1:number, x2: number][]<br />或<br />[x1:number, x2: number][][]                                  | 否       | 标注点集合，`[x1:number, x2: number]`代表每个点坐标。<br />由于一般 points 都是和 boxes 同时存在，一个 box 可以对应多个点，所以额外支持了`[x1:number, x2: number][][]`的数据结构。 |
| masks    | number[][][]                                                                                        | 否       | 遮罩点阵集合, `number[][]`是一个二维数组，代表 mask 的`长 x 宽`点阵。                                                                                                              |
| polygons | [x1:number, y1:number, x2:number, y2:number,<br />x3:number, y3:number,<br />x4:number,y4:number][] | 否       | 不规则多边形坐标点集合。                                                                                                                                                           |
| labels   | string[]                                                                                            | 否       | 标注文本值。                                                                                                                                                                       |

##### 额外属性

| 属性     | 类型   | 是否必填 | 描述                 |
| -------- | ------ | -------- | -------------------- |
| boxes    | object | 否       | 标准四边形样式设置   |
| points   | object | 否       | 标注点样式设置       |
| masks    | object | 否       | 遮罩样式设置         |
| polygons | object | 否       | 不规则多边形样式设置 |
| labels   | object | 否       | 标注文本样式设置     |

**boxes**

| 属性      | 类型   | 是否必填 | 描述                            |
| --------- | ------ | -------- | ------------------------------- |
| lineWidth | number | 否       | 线框宽度，默认值为 6，单位为 px |

**points**

| 属性 | 类型   | 是否必填 | 描述                               |
| ---- | ------ | -------- | ---------------------------------- |
| size | number | 否       | 标注点大小，默认值为 10，单位为 px |

**masks**

| 属性   | 类型     | 是否必填 | 描述                                                                                                                         |
| ------ | -------- | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| colors | number[] | 否       | masks 的色值配置，该值为一个色值数组，色值依次对应 masks 的推理结果。<br />不填写该字段会自动生成对应 masks 数量的随机色值。 |

**polygons**

| 属性 | 类型   | 是否必填 | 描述                            |
| ---- | ------ | -------- | ------------------------------- |
| size | number | 否       | 线框宽度，默认值为 6，单位为 px |

**labels**

| 属性       | 类型                                                     | 是否必填 | 描述                                                                                                                               |
| ---------- | -------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| type       | enum 类型，值为 'point' &#124; 'box-center' &#124; 'box' | 否       | 标注文本位置，值为`point`时会和标注点绑定、为`box-center`时在四边形的正中心，为`box`时在四边形的左上角。<br />默认值为`box-center` |
| indexLabel | boolean                                                  | 否       | 设置该字段后，会根据推理结果的`points`或`boxes`生成值为索引 label，即使推理结果中没有返回`labels`。                                |

#### ImageSegmentation

图像分割组件，对`ImageDraw`组件的封装，专用于用于处理图像分割类任务场景。<br />**注：** 当使用该组件时，输入组件必须为`ImageUploader`或`ImageCanvas`。

##### 数据类型

object，字段如下：

| 属性   | 类型                                               | 是否必填 | 描述                                                                                          |
| ------ | -------------------------------------------------- | -------- | --------------------------------------------------------------------------------------------- |
| boxes  | [x1: number, y1: number, x2: number, y2: number][] | 是       | 标准四边形坐标点集合，`[x1: number, y1: number, x2: number, y2: number]`代表每个 box 的坐标。 |
| masks  | number[][][]                                       | 是       | 遮罩点阵集合, `number[][]`是一个二维数组，代表 mask 的`长 x 宽`点阵。                         |
| scores | string[]                                           | 是       | 每个分割图像的置信度。                                                                        |
| labels | string[]                                           | 是       | 标注文本值。                                                                                  |

## 音频

### 输入组件

#### AudioUploader

标准的音频上传组件，可以支持用户路由或手动上传音频文件。

##### 数据类型

string

##### 额外属性

| 属性              | 类型                                                         | 是否必填 | 描述                                                                                                                              |
| ----------------- | ------------------------------------------------------------ | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| sampleRate        | number                                                       | 否       | 用户录音时的音频采样率。<br />默认值为 16000，即 16k 采样率。                                                                     |
| label             | Record<string, any>                                          | 否       | 配置额外的提示信息                                                                                                                |
| type              | enum 类型，值为 'recording' &#124; 'upload' &#124; 'default' | 否       | 支持的音频上传模式，`default`代表同时支持录音和上传，`upload`代表仅支持上传，`recording`代表仅支持录音。<br />默认值为`default`。 |
| recordingDuration | number &#124; false                                          | 否       | 录音的上限时长，可选值为数字（单位：秒）或`false`，如果值为`false`则代表没有上线值。<br />默认值为 15。                           |

**label**

| 属性      | 类型   | 是否必填 | 描述             |
| --------- | ------ | -------- | ---------------- |
| label     | string | 是       | 提示信息文本。   |
| bgColor   | string | 否       | 提示信息背景色。 |
| textColor | string | 否       | 提示信息文本色。 |

| min           | number       | 否       | 列表最小长度，默认值为 `1`。                                     |
| max           | number       | 否       | 列表最大长度。                                                   |

## 视频

### 输入组件

#### VideoUploader

标准的视频上传组件。

##### 数据类型

string

#### VideoCanvas

视频绘制组件，在上传视频的基础上增加了绘制框选目标的功能。<br />**注：** 由于该组件会产生两个输入值，所以需要占用两个 inputs 元素的位置，需要配合`Empty`组件使用。

```yaml
widgets:
  - inputs: # 第一个元素对应上传的图片，第二个字段对应框选的位置坐标
      - type: video
        displayType: VideoCanvas
      - displayType: Empty
```

##### 数据类型

string、[x1, y1, x2, y2]

### 输出组件

#### Video

标准的视频输出组件

##### 数据类型

string

#### VideoSegmentation

视频分割组件，用于将不同的视频帧分段展示。

##### 数据类型

{ frames: [number, number]; timestamps: [string, string] }[]<br />每一项都包含视频起始结束帧和事件的列表。

| 属性       | 类型                         | 是否必填 | 描述                                             |
| ---------- | ---------------------------- | -------- | ------------------------------------------------ |
| frames     | [start: number, end: number] | 是       | 每一段的起始和结束帧                             |
| timestamps | [start: string, end: string] | 是       | 每一段的起始和结束时间，时间格式为：`hh:mm:ss`。 |

#### VideoDraw

视频标注组件，用于对参与推理的视频返回对应的标注结果。与图片标注不同，由于性能问题，不包含`masks`，目前只包含`boxes`数据。<br />**注：** 当使用该组件时，输入组件必须为`VideoUploader`或`VideoCanvas`。

##### 数据类型

object，字段如下：

| 属性       | 类型                                                                                                                 | 是否必填 | 描述                                                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| boxes      | [x1: number, y1: number, x2: number, y2: number][]<br />或<br />[x1: number, y1: number, x2: number, y2: number][][] | 否       | 包含有每一帧标准四边形坐标点的集合，`[x1: number, y1: number, x2: number, y2: number]`代表每个 box 的坐标。<br />这里支持每一帧对应单个或多个 box 的情况。 |
| labels     | string[]<br />或<br />string[][]                                                                                     | 否       | 与 box 依次对应的标注文本值。                                                                                                                              |
| timestamps | string[]                                                                                                             | 是       | 每一帧所对应的具体时间节点，时间格式为：`hh:mm:ss`。                                                                                                       |
