# 成为社区认证模型

本篇文章介绍如何成为魔搭社区的已认证模型。

为了让ModelScope社区的模型的可用性更高、质量更佳、更方便用户使用，魔搭社区提供帮助贡献者进行可用性认证的服务。针对社区认证的模型，将会在模型上有认证标，帮助用户更好地筛选模型。也将得到更多的流量和排序倾斜哦！<br />![image.png](./_resources/v1.5p3.png)

贡献者若想申请魔搭社区认证，可按如下步骤操作：<br />在【模型详情页】-【设置】-【申请社区认证】，点击申请后会弹窗提示达到认证目标需要的条件：<br />![image.png](./_resources/v1.5p4.png)

若要成为社区认证的模型，需要三方面的条件：

1. 模型示例代码可用。您可在readme文档或者在quickstart文档中提供运行该模型的示例代码，提交认证申请后将由ModelScope社区工作人员对您的模型示例代码可用性进行测试验证。
2. 模型介绍内容完整。在readme文档中提供必要的模型介绍，例如模型原理、模型使用限制、指标、环境依赖、应用场景、参考论文等介绍，内容不限，但请确保用户可以通过该readme内容清晰了解该模型的作用。
3. 模型Demo可用。若您的模型接入的demo工具，请自测该模型demo有默认示例，并且示例可成功运行，提交认证申请后ModelScope社区工作人员会进行二次测试确认。若您的模型本身没有Demo服务或无需提供Demo服务，此项也可勾选后提交。

请务必确保您的模型符合上述条件后再申请社区认证。发起申请后，社区工作人员将在3~5个工作日内完成审核工作。最终结果将通过站内信告知您。

若您的模型审核不通过，将告知对应的未通过理由，请根据拒绝理由调整您的模型示例代码或内容，调整后的模型仍可再次发起认证申请。
