# 1. 玩法选择
在快速生图功能页面，我们提供多种预置玩法供用户选择，包括：

**1.通用玩法**：适合大多数场景，能够根据描述生成高质量的图像。

**2.Flux模型生图**：采用最新的Flux模型，擅长创造细腻、逼真的图像风格。

**3.SD3模型生图**：利用SD3（Stable Diffusion v3）模型，专注于细节丰富、色彩鲜明的图像生成。

**4.动漫风**：专为动漫爱好者设计，轻松创作出具有日漫或美漫风格的艺术作品。

**5.像素风**：复古游戏迷的最爱，生成像素化的图像，重温经典游戏视觉。

**6.水墨画**：融合中国传统艺术，生成具有浓郁水墨韵味的图像。

**7.宫崎骏风格**：模仿宫崎骏动画电影中的温馨与奇幻，创作独一无二的动画风格图像。

**8.黏土风**：以黏土动画为灵感，创造出独特而富有童趣的3D效果图像。

用户可以根据自己的喜好和需求选择不同的玩法，通过文字激发无限的视觉想象，生成自己想要的图片。

![image.png](./_resources/玩法选择.png)

# 2. 图像描述
用户需输入具体的描述或关键词，系统会根据这些信息生成相应的图片。

图像描述可以是文字描述、颜色、风格、情感等方面的信息: 如“夏日海滩的落日景色，温暖色调”，支持中文与英文输入（最多输入200字字符）。


# 3. 图片比例
用户可以选择不同的图片比例来生成图片。我们提供多种比例供用户选择，包括1:1（正方形）、1:2（竖长形）、4:3（宽屏）、3:4（竖屏）、16:9（高清视频比例）、9:16（手机屏幕比例）等。用户可以根据自己的需求来选择合适的比例，生成自己想要的图片。

![image.png](./_resources/图片比例.png)

# 4. 生图数量
用户可以选择生成1张、2张、4张、8张图片。
用户可以根据自己的需求来选择生成的数量，一次性生成自己想要的图片张数，方便进行效果比较。


# 5. 生成图片
**操作流程**：用户在选定玩法、输入提示词、选择图片比例及数量后，点击“开始生图”按钮即可启动生成过程。 

**等待提示**：鉴于资源分配与服务器性能管理，系统可能在高峰时段实施排队机制。请用户耐心等待，我们会尽快处理您的请求。

**高级功能引导**：如果快速生图生成的图片无法满足您对图像的需求，我们推荐您一键跳转到专业生图页面，可供探索更多高级生图功能。

# 6. 生图历史
用户可以点击生图历史按钮，来查看自己之前生成史图片，悬浮在图片上方，您将看到以下功能按钮：

1. 下载原图: 一键保存原图至本地；
2. 加载参数：一键导入该图片的生图参数，立即在当前页面重现创作过程，便于您调整和优化；
3. 跳转到专业生图：直接进入专业模式，开启更深度的图像编辑体验；
4. 生成分享：快速生成图片的专属分享链接，一键复制，与朋友、家人或社交媒体上的粉丝共享您的视觉故事。
