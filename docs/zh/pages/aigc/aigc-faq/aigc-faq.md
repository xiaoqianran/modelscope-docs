# 常见问题整理

📢 感谢大家对魔搭 AIGC 专区模型的热情和支持，这里我们整理了 AIGC 专区使用过程中遇到的一些常见问题。

### Q1: 为什么我的训练任务排了很久， 仍旧是“等待中”？
每个训练任务均会被分配相应的优先级， 满足以下条件的训练任务具有最高优先级：（1）每个用户当天的第一个训练任务；（2） 将模型设置为公开的训练任务。 不满足上述两个条件的任务优先级更低，会被其他高优先级训练任务插队。

### Q2: 为什么我的训练任务训练了很长时间后显示失败了？
每个训练任务都均有最长训练时间限制。超出该时间限制，训练任务将自动中断。 平台会确保该训练时间限制， 可以充分满足一个正常 LoRA 的训练时长需求。

### Q3: 为什么我无法训练了 / 训练额度减少了？
请务必遵循使用开源社区免费训练资源得到模型的使用规范。如需将模型搬运至其他平台时， **请明确标注模型来源是“魔搭 AIGC 专区”**。平台保留对违反该规范的用户相关账号进行限制的权利。

### Q4: 使用魔搭AIGC免费资源训练出来的模型，所有权是我自己的吗？
根据社区用户协议准则，通过魔搭平台AIGC专区生成的内容，包括训练得到的模型LoRA以及图片视频等，其所有权**由创作者本人以及魔搭平台共同拥有**。如需转载，请务必注明内容来源来自于“魔搭AIGC专区”，并带上原创作者信息。 这是对社区整体以及创作者劳动成果的基本尊重，也是维护社区健康生态的重要准则。若违反这一基本原则，平台保留处理和追责的权利。
