欢迎来到魔搭社区AIGC专区的Lora模型训练板块！

AIGC专区的 的 LoRA 训练模块允许你基于少量图片（或视频）素材，通过使用LoRA（Low-Rank Adaptation），
用户能够基于现有大型模型（如 Qwen-Image 等）进行快速微调，训练得到自己想要的专属风格LoRA模型，创造出具有独特风格的图像生成器！

和使用自己的电脑训练 LoRA 相比，使用魔搭平台有以下优势：
- **无需配置复杂的 Python、GPU 环境**，整个流程在网页上操作即可
- **社区免费提供的算力资源**，显卡性能优于 RTX 4090
- **支持训练资源需求更高的 图像生成（如Flux.1）、视频生成（如万相2.1）LoRA**，并且可以选择任意的底模
- **模型、参数、训练任务等信息严格鉴权**，不用担心被其他人窃取你的信息

> [!NOTE]
> 更多训练资源使用相关的问题，请参考[AIGC专区常见问题](./AIGC专区常见问题.md)。

# 第一步：准备训练数据
训练 LoRA 的第一步是在本地准备你的数据集。

以下图中的数据集为例，我们准备了两个子文件夹，分别代表拟训练的两类概念（场景、猫），文件夹下划线前面的数字代表该文件夹里面的图片我们期望的重复次数。
![image.png](./_resources/文件目录.png)

单个文件夹中，包含了训练图片和对应的 Prompt，如下图所示。有三个注意事项：

1. 保持每张图片和对应 Prompt 的文件名一致，否则训练脚本将无法准确读取到图片对应的 Prompt
2. 保证每个 Prompt 中都包含了你期望的触发词，否则 LoRA 可能无法生效
3. 确保 Prompt 和实际的图片内容保持一致，否则 LoRA 效果可能不及预期

![image.png](./_resources/子文件目录.png)

在准备好上述两个文件夹后，将它们使用 zip 进行压缩，得到一个压缩包。在第二步中我们会上传该压缩包，以供后续训练使用。

![image.png](./_resources/压缩.png)

# 第二步：创建训练任务

## 模版选择  

在训练页面，首先需要根据自己的具体需求，选择想要的训练模版。当前社区提供以下预置训练模版：

- Wan2.1-1.3B：此模板支持通义万相2.1-1.3B的文生视频模型LoRA训练，适用于创建高质量的文生成视频内容，帮助您快速实现创意构想。
- 麦橘超然：此模版基于Flux.1架构演进，专注于生成高质量的人像图像，擅长创造出真实、细腻且富有光影感的图像内容。
- Flux.1-Dev: 此模板基于前沿的混合架构，结合多模态和并行扩散变压器模块，实现了图像生成性能与效果之间的完美平衡，适用于多样化的风格创作。
- 动漫: 面向动漫创作者与粉丝，此模版优化了色彩饱和度、线条清晰度，特别适合生成具有日韩或欧美动漫风格的作品。
- 写实: 强调细节真实感与光影效果，适合追求高保真度图像生成的用户，如风景画、人物肖像等，能够模拟出接近照片级的真实质感。
- 自定义：此模版适用于有更多自定义需求的用户，可以按需设定个性化底模与参数打造你的专属模型。

## 上传图片

在选择底模后，我们需要通过拖拽或点击的方式，上传训练所需的图片，可以直接把第一步中准备的本地 zip 压缩包上传到 Muse。（也支持直接选择已经上传的图片数据集）
![image.png](./_resources/上传图片.png)

注意不同类型的LoRA训练模版对上传图片的要求所有差异，具体可以参见页面具体提示信息。
![image.png](./_resources/图片要求.png)

## 图片预处理

在上传图片数据集之后，平台提供了灵活的预处理选项:
1. 用户可以根据自身的需求对图像进行**裁剪**，以保障所有输入数据的格式一致性。 
2. 用户可以使用我们提供的**打标功能**来为自己的图片添加语义信息。例如基于**通义千问**模型或**JoyCaption**模型为您的图像补充丰富且准确的文本描述。

![image.png](./_resources/图片打标.png)

训练任务成功发起之后，您也可以在 **模型训练** -> **数据管理** 页面查看您当前任务所产生的训练数据集与其对应的标注信息，并且支持导出与二次修改。

## 参数设置

接着我们需要填写训练任务的基本信息，包含：
- **单张次数**：定义每张图片在训练过程中被使用的次数，调整参数可影响模型对每个样本的学习深度。
- **训练轮数**：设置模型在整个数据集上训练的完整遍历次数。适当调整此参数以平衡训练效果与效率。
- **LoRA模型名称**：自定义将要训练的模型名称。
- **模型触发词**（非必填）：请输入一个对应训练概念的单词，**尽量避免使用常见英文单词**，建议使用训练概念的拼音。
- **模型可见性**：训练完成后模型是否公开。
> 注意：公开模型不仅能获得更高的训练优先级，还能促进社区内的资源共享和技术交流。

![image.png](./_resources/参数设置.png)

如果您有更进阶的训练需求，也可以点击参数设置右侧的**专业参数**面板，以自定义设置更多相关训练参数。

![image.png](./_resources/详细参数.png)


## 开始训练
确认基础信息无误后，即可点击“开始训练”按钮，提交本训练任务。


# 第三步：查看训练进度

提交训练任务后，在**训练管理**界面可以看到一个新建的任务卡片。

我们可以点击该卡片查看本次训练任务的详情，以及当前的任务状态。

当前训练任务有如下几个状态：
- 排队中
- 训练中
- 训练完成
- 训练失败
- 超时终止

![image.png](./_resources/训练管理.png)

任务处于"超时终止"状态时，您可以通过点击任务卡片右上方的"重启"按钮来继续训练。

![image.png](./_resources/超时终止.png)

任务处于“训练中“状态时，您可以根据训练详情上方的进度条查看实时进度。


而在具体某个任务的详情页中，左下角展示的是 LoRA 保存点信息，每个 LoRA 保存点（Checkpoint）会根据第二步中详细参数中的样图设置生成一张**实时样图**。
此外，右侧展示的是训练参数详情。


# 第四步：训练完成，前往生成
在训练任务的状态变为“训练完成”后，你就可以直接点击详情界面的“开始生成”按钮，在对应的界面使用刚训练好的LoRA进行个性化创作了。

![image.png](./_resources/训练详情.png)
