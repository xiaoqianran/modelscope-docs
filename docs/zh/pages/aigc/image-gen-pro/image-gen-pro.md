# 1.提示词
在图像生成领域，"Prompt"（提示词）是指通过文字指令引导 Stable Diffusion（以下简称 SD）生成理想图像的做法。

Prompt 分为两种类型：正向提示词（Positive Prompt）和负向提示词（Negative Prompt）。正向提示词涵盖你希望在图像中呈现的内容，如一轮壮丽的落日或一只可爱的小狗；而负向提示词则指定你希望图像中避免出现的元素，比如障碍物或不需要的细节。 

Prompt 通常由简洁的英文短语组成，描述图像的主题、材质、风格、色彩调和灯光等各方面信息。


![image.png](./_resources/prompt.png)


# 2.提示词优化
在创建美观图片的过程中，构思一个恰当的 Prompt 是关键步骤。正确撰写 Prompt 需要考虑众多要素，如字数、词序和关键词的权重等。此外，Stable Diffusion（SD）本身并不直接理解文本，而是借助 CLIP 模型把 Prompt 转换为它能够识别的 token。由于 CLIP 模型仅以英文材料为训练基础，因此，Prompt 必须使用英文。 

针对这一挑战，Muse 推出了“提示词优化”功能。该功能借助大型语言模型（LLM）的创造力，以用户的输入为基础，进一步丰富和扩展 Prompt。

> 帮助用户解决编写 Prompt 的复杂性以及不能使用中文的限制

![image.png](./_resources/提示词优化.png)

# 3.提示词翻译
“提示词优化”功能的一个潜在问题在于，大型语言模型（LLM）可能会过度发挥“想象力”，导致生成的Prompt中出现一些用户不期望的元素。如果您不希望 LLM 过度扩充 Prompt，同时面临着忘记某些中文对应英文单词怎样拼写的情况，您可以借助“提示词翻译”功能，将中文直接翻译成英文。

> 这样既可以精确控制 Prompt 的内容，又克服了语言障碍。

![image.png](./_resources/提示词翻译.png)

# 4.模型选择
Stable Diffusion (SD)模型主要可分为以下几种类型，更详尽的信息可以查阅模型[类型介绍](https://www.uisdc.com/stable-diffusion-guide-4):

**1.Checkpoint**：即基础模型，根据模型结构和参数大小有多个版本可选，生成图片时是必须选择的；

**2.LoRA**：用于固定特定目标特征的形象，这些特征可包括动作、年龄、表情、服装以至于材料、视角和画风等。这种类型在动漫角色复现、画风转换和场景设计等领域有广泛应用，生成图片时为可选项；

**3.VAE (变分自编码器)**：负责将潜在空间中的图像信息转换成正常可视图片，生成图片时可选。   

Checkpoint 和 LoRA 是相对比较常用的模型类型，用户可根据所需生成图片的风格来选择合适的模型。通过“模型管理”功能，用户**能够根据模型类型、名称、SD 版本等条件进行筛选**，从而找到最适合的模型配置。

# 5.生图基本参数
生成图片时，我们会设定几个基本参数，详细信息可查阅[《十分钟搞懂 Stable Diffusion 的基础概念》](https://juejin.cn/post/7276808079143780389):

**1.采样方法**：这是去除生成图片中的噪声所使用的算法。通常，选用DPM++ 2M Karras就足够了；

**2.提示词引导系数**：此参数调节生成图像与原始文本之间的关联度。较低的值让生成图像的创造性更高，而较高的值则强化文本内容对图片的制导作用；

**3.随机种子**：它使得在其他参数相同的条件下，不同的随机种子会生成风格有别的图片，为创意提供了几乎无限的可能性。相反，使用相同的种子会生成一致的图像。-1代表每次生成都会使用一个不同的随机数；

**4.采样步数**：这代表模型在降噪过程中的迭代次数。提高采样步数可提高图像的细节和精确性，但同时也会延长生成时间。不同的采样器可能需要不同的采样步数以获得相似的去噪效果。通常，设定采样步数在20到30之间是比较常规的选择；

**5.生成图片数量**：单次操作可以生成的图片数量；

**6.宽度**：所生成图片的宽度尺寸；

**7.高度**：所生成图片的高度尺寸。

通过调整以上的参数，用户可以控制图片生成的过程和结果。

# 6.图生图之局部重绘
局部重绘是一个强大的功能，它允许用户通过使用蒙版(mask)将图片中的特定区域遮盖住，然后让 Stable Diffusion（SD）根据 Prompt 对这些被遮盖的区域进行重新绘制，同时保持图像的其它部分不变。这个过程赋予了用户更细致地决定图片中应出现哪些元素的能力，显著提升了图片生成的质量。 局部重绘的输入主要包括：

**1.原图片**：需要进行重绘的图片本体；

**2.蒙版**：一张黑白图片，其中白色部分标识了需要重绘的区域；

**3.重绘幅度**：这个参数控制重绘的范围。数值设得越高，表示模型在重绘时有更高的自由度，因此生成的图像与原图相比，变化程度也越大。 关于蒙版，用户有多种选择：**可以直接上传已有的蒙版文件、使用画笔工具手动绘制，或者借助“Muse 图片前处理功能”来快速创建。**

![image.png](./_resources/图生图.png)

# 7.图片前处理
在进行“局部重绘”时，用户需要提供待处理的原始图片以及一个蒙版，后者用于界定需要重绘的区域。对于形状较为复杂的物体，精确地绘制蒙版可能相当费时费力。针对这一问题，Muse 提供了一个便捷的解决方案 —— 在“局部重绘-上传蒙版”环节，Muse 带有“自动抠图”功能，用户**可以一键生成目标物体的蒙版。**

![image.png](./_resources/抠图.png)

Muse 提供几种主要的抠图技术： 

**1.主体抠图**：自动定位并提取图片中的主体； 

**2.商品抠图**：自动识别并提取图片中的商品； 

**3.人体抠图**：提供选项以仅提取皮肤、衣物或背景。 

在使用“局部重绘”功能时，系统将**对蒙版中的白色区域进行重绘。** 
因此，建议您从抠图结果中挑选最适合的蒙版图片进行操作。

![image.png](./_resources/抠图并选择蒙版.png)


# 8.高清修复
高清修复技术通过AI算法将图片从低分辨率转换为高分辨率，显著提升了图片的细节和清晰度。此技术的应用包括几个关键的可调参数：

**1.模型（算法类型）**：建议使用 R-ESRGAN 4x+ 对标准图片提升。对于动漫风格的图片，使用 R-ESRGAN 4x+ Anime 6B 更为合适。

**2.放大倍数**：这是图片分辨率放大的倍数。由于显存容量的限制，通常可选择的范围是 1~2 倍。

**3.重绘幅度**：这决定了提升分辨率过程中的创作自由度。数值越高，允许的自由程度也越大，意味着图片在细节重建过程中可引入更多的创新元素。

通过这些参数的调整，用户能够根据具体需求优化图片的修复效果，实现从简单的清晰度提升到复杂的艺术重绘之间的广泛应用。

![image.png](./_resources/高清修复.png)



# 9.ADetailer
ADetailer 是一个专门用于改善生成图像中人物脸部或手部扭曲和模糊问题的工具。它提供了以下可调节参数来精细控制修复过程。更多关于此工具的详细信息，可以访问[Adetailer: 自动修复脸部和手部](https://stable-diffusion-art.com/adetailer/):

**1.模型**：指定用于修复的算法。对于脸部修复，推荐使用 face_yolov8s.pt 模型；而手部修复则建议使用 hand_yolov8s.pt 模型。

**2.正向提示词**：定义您希望在修复的脸部或手部中呈现的细节。

**3.负向提示词**：指定您不希望在修复的脸部或手部中出现的细节。

通过这些参数的调整，用户可以根据自己的需求，对生成的图像中的脸部或手部进行精确的修复，以提高图像的质量和真实感。

# 10.ControlNet
在ControlNet推出之前，生成图像的过程对用户来说充满未知，就像是在抽取未知的卡片一般，无法预测 AI 将会生成什么样的图片，给用户体验带来不确定性。然而，有了 ControlNet 之后，我们可以更精确地控制图像的生成过程，例如上传草图让AI进行着色渲染，或是控制人物姿态、生成线条图等。 ControlNet 提供了若干可调整参数，以实现对图像生成过程的精细控制。更多的细节和深入指导可以参考 ControlNet: 完整指南：

1. 控制图：用于提供图像生成控制信息的图片 **（注意上传的图片长或宽均需可被16整除，否则会报错）**。
2. ControlType（控制类型）：支持多种控制方式：
   - Canny：用于边缘检测，可提取图像轮廓，适合保留原始图像构图；
   - Depth：从参考图获取深度信息；
   - Lineart：转换图像为线条艺术风格的轮廓，适用于简单绘图；
   - OpenPose：检测人体关键点，如头部、肩膀、手的位置等，有助于复制人体姿势而非其他详细信息；
   - SoftEdge：类似于 Canny，但可精简复杂细节中的图像轮廓；
   - Scribble/Sketch：将参考图转换为涂鸦或手绘风格；
   - ControlNet模型：每种 ControlType 都配备了多个模型算法选择，每个都在效果上有所差异，但整体符合 ControlType 的描述；
3. 控制权重：决定控制图对于提示语的重视程度，与提示中的关键词权重相似。数值越小，ControlNet 对控制图的遵循度越低；
4. 预处理器：不同 ControlType 需要不同的预处理器，将原始图片处理成 ControlNet 处理所需的形式。通过点击“预览预处理结果”可以查看处理后的图片；
5. 引导开始：标示 ControlNet 激活的步骤，0 代表从第一步开始；
6. 引导结束：指示 ControlNet 停止激活的步骤，1 表示最后一步。


虽然可以叠加多个ControlNet以达到多方面的图片控制，但由于显存大小限制，最多同时使用三个 ControlNet。
