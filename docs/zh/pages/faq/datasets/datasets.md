# 数据集常见问题

## 创建相关
### Q1：为什么我创建数据集时候出现了“初始化项目”失败的错误？<br />
这个可能是由于一些存量账号之前在Git侧未加入到您选择的“所有者”空间下，遇到这种情况，可以联系我们进行后台操作。

### Q2：创建数据集后，文件列表内提示“Readme.md文件存在语法错误，无法正确解析，请尽快修复”以及当前“当前PYTHON文件为空，请尽快完善文档内容”怎么办？
为了保障平台内数据集的质量，我们针对上传的readme文件进行了内容和语法检查，若出现报错，您可以自行检查该数据集内是否存在以下问题：
1. yaml header中是否包括task，license信息，且整体readme是否可以解析通过
2. markdown section中是否包含>200个字符
3. 若该数据集托管到公开host，python文件是否为空<br>
具体数据集新建可参考文档[托管到ModelScope](https://modelscope.cn/docs/%E6%89%98%E7%AE%A1%E5%88%B0ModelScope%E6%95%B0%E6%8D%AE%E9%9B%86%E5%88%9B%E5%BB%BA%E6%B5%81%E7%A8%8B)和[托管到公开Host](https://modelscope.cn/docs/%E6%89%98%E7%AE%A1%E5%88%B0%E5%85%AC%E5%BC%80Host%E6%95%B0%E6%8D%AE%E9%9B%86%E5%88%9B%E5%BB%BA%E6%B5%81%E7%A8%8B)。

## 预览相关
### Q3: dataset_infos.json为什么不能修改?<br />
该文件是自动生成的文件，用于支持前端预览的，用户不需要手动编辑，如果发现有误，可以联系我们。其他数据集的文件规范，参考《数据集文件规范》一文

### Q4: 为什么我已经上传好了数据文件，没看到预览生成?<br />
预览生成的动作是一个异步执行的操作，对于一般大小的数据集，请耐心等待3-5分钟，如果遇到大的数据集，需要等待更久，如果发现长时间没有响应，可以联系我们。

### Q5: 如何触发预览？<br />
当修改数据文件（除README.md、dataset_infos.json）后，系统会自动触发重新预览。

## 维护相关
### Q6: 我想更改数据集归属的空间，可以么？<br />
目前不支持这样的功能，需要您在新的空间下重新建一个。

### Q7: 目前数据文件如何上传？<br />
目前有两个途径上传数据文件，1：通过Web端页面上传，支持单文件、多文件和文件夹上传。2：通过git上传，如果上传大文件，需要使用git lfs。

### Q8: Readme当中的tag如何填写？<br />
当您点击Readme.md右侧的 编辑按钮时候，会出现编辑界面，右上角有一个“使用模板编辑器”功能，可以帮您快速生成一段tag，然后粘贴进来即可。尤其注意，Readme当中分隔 yaml 部分和 后续markdown部分的三个短横线"---"后，不要带多余的空格，请直接换行。

### Q9: SDK modelscope==1.13.2 或更高版本，对数据集进行了全面优化，使用SDK加载数据集时遇到错误，请尝试将SDK升级到最新版本<br />
